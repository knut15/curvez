# component: LabCard

purpose: 기록 하나를 목록에서 대표한다. 카드 전체가 상세로 가는 하나의 링크다

## props

| 이름    | 타입                            | 필수 | 기본값 | 의미                                                |
| ------- | ------------------------------- | ---- | ------ | --------------------------------------------------- |
| slug    | string                          | O    | —      | `/labs/[slug]` 로 이동할 대상                       |
| title   | string                          | O    | —      | 기록 제목. 2줄까지 보이고 넘치면 말줄임             |
| summary | string                          | O    | —      | 한 줄 요약. 3줄까지 보이고 넘치면 말줄임            |
| status  | `진행 중` \| `멈춤` \| `마무리` | O    | —      | 카드 맨 위 배지. 점 + 글자                          |
| date    | string (YYYY-MM)                | O    | —      | 정렬 기준이자 배지 옆에 표시되는 시점               |
| tags    | string[]                        | X    | []     | 주제 태그. 3개까지 보이고 나머지는 "+N" 으로 접는다 |

**CaseCard 와 다른 점은 상태 배지 하나다.** 나머지 규칙(전체가 링크 하나, 줄 수 제한, 반경,
hover·focus)은 같다.
**이유:** 두 목록이 같은 화면에 나오지는 않지만 방문자는 같은 사이트에서 연달아 본다.
카드의 구조가 다르면 두 목록이 다른 사이트처럼 읽힌다.

**배지를 제목 위에 둔다.**
**이유:** 이 목록에서 먼저 읽어야 하는 것이 "얼마나 왔나" 다. 제목 아래로 내리면 요약과
태그 사이에 끼어 메타 정보 덩어리로 묻힌다.

## states

| state         | 트리거        | 시각 변화                                                                            |
| ------------- | ------------- | ------------------------------------------------------------------------------------ |
| default       | —             | bg=--card, border=--border, radius=`rounded-lg`. 칩·점은 `rounded-sm`/`rounded-full` |
| hover         | 포인터 진입   | bg=--accent, 테두리 유지. 그림자·이동 없음                                           |
| focus-visible | 키보드 포커스 | outline 2 + offset 2, color=--ring                                                   |
| pressed       | :active       | 시각 변화 없음. 링크라 누른 상태를 따로 표시하지 않는다                              |
| disabled      | 없음          | 이 컴포넌트에 비활성 상태가 없다. 링크는 항상 유효하다                               |
| loading       | 없음          | 정적 생성이라 카드가 로딩 중인 구간이 없다                                           |
| error         | 없음          | 데이터는 빌드 시점에 확정된다. 런타임 에러가 없다                                    |

상태 점 색: `진행 중` = --brand-accent, `멈춤`·`마무리` = --muted-foreground.
**색만으로 상태를 말하지 않는다.** 점 옆에 상태 글자가 항상 함께 있다.

## a11y

- a11y:label — 카드 전체가 링크다. 접근 이름은 title 하나로 충분하므로 aria-label 을 중복 지정하지 않는다. 상태·날짜·태그는 링크 이름에서 제외한다
- a11y:focus — 카드당 포커스 대상은 **하나**다. 내부에 별도 링크를 두지 않는다. 포커스 순서는 DOM 순서와 같다
- a11y:contrast — 제목 fg=--card-foreground / bg=--card 라이트 16.73 · 다크 14.84. 상태·요약·태그 fg=--muted-foreground / bg=--card 라이트 5.59 · 다크 7.34. 상태 점은 `aria-hidden` 이라 대비 대상이 아니다
- a11y:target — 카드 전체가 클릭 영역이라 24x24 를 크게 넘는다. 카드 사이 간격 gap-4(16px)로 인접 8px 규칙을 만족한다
- a11y:role — link. 카드를 button 으로 만들지 않는다. 새 탭·주소 복사가 막힌다

## responsive

- <768 1열 전체 폭 / >=768 grid 안에서 동일 높이. 제목·요약 줄 수 제한으로 높이를 맞춘다
