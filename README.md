# city-presets

사진 한 장에 열두 가지 색을 거는 프리셋 묶음. 도시 이름은 찍을 장소가 아니라 **색의 이름**이다.

기획 문서(PRD)는 Obsidian 볼트의 `Studio-Curvez/아이디어/도시 필터 — 사진 한 장을 열두 가지 무드로.md` 가 정본이다.

## 파일

| 경로 | 무엇 |
| --- | --- |
| `grade.py` | **값의 정본.** 열두 개의 슬라이더 값과 적용 순서 |
| `frame.py` | 사진 아래에 적용값 스트립을 붙인다 |
| `base/` | 기준 사진 두 장. 야외(주)와 실내(부) |
| `reference/prompts.tsv` | 초기 레퍼런스 이미지를 만든 프롬프트. 기록용 |

## 돌리는 법

```bash
python3 grade.py base/01-base-outdoor.png   # graded/<원본이름>/ 에 12장
python3 frame.py                            # framed/ 에 값 스트립을 붙인 12장
```

`graded/` 와 `framed/` 는 커밋하지 않는다. 위 두 줄로 언제든 다시 나온다.

## 값을 고칠 때

**`grade.py` 의 `PRESETS` 만 고친다.** 사진 아래 찍히는 숫자는 `frame.py` 가 거기서 읽어 오므로
따로 고칠 곳이 없다. 값과 화면이 어긋날 자리를 만들지 않는다.

고친 뒤에는 열두 개가 여전히 서로 갈리는지 확인한다. 판정 방법은 PRD 의
`열두 개가 정말 열두 개인지 검사한다` 에 있다.

## 기준 사진

- `base/01-base-outdoor.png` — 지상 승강장, 맑은 날. 하늘·자연광·초록이 있어 야외 계열을 판정한다
- `base/00-base.png` — 지하 승강장, 형광등. 인공광에서의 화이트밸런스와 깊은 그림자를 판정한다

한 장으로는 열두 개를 다 판정할 수 없다. 하늘이 없는 사진에서는 맑은 날 계열이 먹을 자리가 없다.
