# apps

배포되는 것을 둔다. 각 앱은 자기 배포 대상과 실행 명령을 스스로 갖는다.

## 규칙

- **앱은 다른 앱을 import 하지 않는다.** 공유해야 하는 것이 생기면 `packages/` 로 올린다
- **앱끼리 파일을 상대 경로로 넘나들지 않는다.** 경계를 넘는 참조는 패키지 이름으로만 한다
- 앱 안의 구조(라우팅·레이어)는 그 앱이 정한다. 여기서 강제하지 않는다

**이유:** 앱 사이의 직접 참조는 배포 단위를 조용히 묶는다. 한쪽을 고치면 다른 쪽이 깨지는데,
그 사실이 배포 시점에야 드러난다. 공유가 필요하다는 신호는 패키지로 올리라는 신호다.
