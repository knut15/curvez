## 여기 없는 기록

| 무엇                   | 어디에                                                                                      |
| ---------------------- | ------------------------------------------------------------------------------------------- |
| 열두 개의 실제 값      | `../presets/grade.py` 의 `PRESETS`. 문서가 아니라 코드가 정본이다                           |
| 왜 그 값이 됐는가      | `git log`. 붙은 짝을 어떻게 갈랐는지가 커밋 메시지에 수치와 함께 있다                       |
| 이미지를 만든 프롬프트 | `../presets/hero/prompts.tsv`, `../presets/reference/prompts.tsv`                           |
| 레퍼런스 계정 분석     | Obsidian 볼트 `Studio-Curvez/아이디어/포토그래퍼.md`. 이 제품 이전의 기록이라 옮기지 않았다 |

**값을 문서에 옮겨 적지 않는다.** 코드와 문서에 같은 숫자가 두 벌 있으면 한쪽만 고쳐진다.
문서는 "왜 그렇게 정했는가" 를 담고, "얼마인가" 는 코드에서 읽는다.
