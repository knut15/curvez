이 사이트를 만들면서 나온 컴포넌트를 독립 라이브러리로 뽑고, 그것을 보여주는 문서 사이트를
따로 세웠습니다.

소스는 [packages/scopulus-ui](https://github.com/knut15/curvez/tree/main/packages/scopulus-ui)
에 있습니다. **사이트 주소는 배포 뒤에 채웁니다.**

## 무엇을 만들었나

컴포넌트 20종과 그 문서 사이트입니다. 근거가 둘로 갈립니다.

- **9종은 실측입니다.** 이 사이트의 화면 코드에서 같은 Tailwind 클래스 문자열이 몇 번
  반복되는지 세어 뽑았습니다. `PageShell` 은 5회, `AppLink` 는 6곳, `Card` 는 2회.
  그 횟수와 `파일:줄` 이 각 스펙의 근거 절에 그대로 있습니다.
- **11종은 받은 것입니다.** shadcn `base-nova` 에서 가져와 토큰만 맞췄습니다. 폼·오버레이·
  피드백·데이터 네 묶음을 덮습니다.

**두 근거를 섞지 않았습니다.** 받은 11종의 스펙에는 `handwork 사용처: 0곳` 이 적혀 있습니다.
섞이면 어느 값이 검증된 것인지 판정할 수 없습니다.

## 어떻게 짰나

### 세는 것부터 했다

디자인 시스템을 만들 때 가장 흔한 실패는 "있으면 좋을 것 같은" 컴포넌트를 먼저 만드는
것입니다. 쓰이지 않는 코드가 남고, 그것이 검증되지 않은 채 다음 사람의 기준이 됩니다.

그래서 먼저 셌습니다.

```bash
grep -rn 'max-w-5xl flex-1 px-5 py-10 md:px-8 md:py-16' src --include='*.tsx'
```

다섯 파일에서 한 글자도 다르지 않게 나왔습니다. 그것이 `PageShell` 이 존재하는 이유의
전부입니다.

**실측이 없는 축에는 값을 정하지 않았습니다.** 그림자가 그렇습니다 — `shadow` 가 앱 전체에서
0건이라, 고도 축을 "쓰지 않는다" 로 확정했습니다. 정했으면 검증되지 않은 값이 남고, 다음
사람은 그것이 결정인지 방치인지 구분할 수 없습니다.

### 게이트가 스스로를 의심하게 했다

검사를 만들고 나서 "실패 0건" 을 그대로 믿지 않았습니다. **일부러 깨뜨려 잡히는지
확인했습니다.**

| 검사     | 만든 결함                                | 결과                |
| -------- | ---------------------------------------- | ------------------- |
| 대비     | 미달 쌍 / 문서 수치 불일치 / CSS 만 변경 | 3종 전부 잡힘       |
| 접근성   | `aria-label` 없는 아이콘 버튼            | `button-name` 위반  |
| 상호작용 | 기대 호출 횟수를 1에서 2로               | 해당 스토리 실패    |
| 버전     | `package.json` 만 올림                   | changelog 와 어긋남 |

접근성 검사에서 첫 시도가 틀렸습니다. 자식으로 넣은 `●` 가 실제 텍스트라 접근 이름이 생겨
전부 통과했고, `aria-hidden` 인 svg 만 남겨서야 위반이 됐습니다. 그대로 넘어갔으면 "검사가
돈다" 고 잘못 믿을 뻔했습니다.

**"실패 0건" 은 그 자체로 아무것도 증명하지 않습니다.** 결함이 있는 입력에도 0건이 나올 수
있기 때문입니다.

### 라이브러리로 뽑으면서 드러난 것

앱 안에 있을 때는 보이지 않던 의존이 셋 드러났습니다.

**토큰이 앱의 CSS 에 있었습니다.** 라이브러리가 앱의 `globals.css` 를 전제하는 구조였습니다.
색·반경을 라이브러리로 옮기고, 앱은 그것을 import 한 뒤 브랜드 색만 더하게 했습니다.
앱의 전역 CSS 가 152줄에서 44줄로 줄었습니다.

**링크 hover 가 없는 토큰을 가리켰습니다.** `AppLink` 가 `--brand-accent` 를 쓰는데 그 토큰은
앱 것이라, 라이브러리 밖에서는 **아무 색도 나오지 않았습니다.** Tailwind 는 없는 토큰의
클래스를 만들지 않으므로 오류도 나지 않고 테스트도 통과합니다 — 조용히 깨져 있었습니다.
값이 완전히 같은 `--ring` 으로 바꿨습니다.

**`Button` 을 줄인 근거가 무너졌습니다.** variant 를 2종으로 줄인 이유가 "이 사이트에 버튼이
들어갈 자리가 둘뿐" 이었는데, 라이브러리가 되면서 `Dialog` 가 세 번째 사용처가 됐습니다.
`outline` 과 `icon-sm` 을 되살렸습니다.

**전제가 바뀌면 결정도 바뀝니다.** 처음 판단이 틀렸던 것이 아니라, 그때의 근거가 지금은
사실이 아닙니다.

## 무엇이 남았나

- **시각 회귀가 없습니다.** 픽셀 단위 변화는 지금 게이트로 잡히지 않습니다
- **다크 모드 테스트가 한쪽만 돕니다.** 테스트는 라이트 기준으로 실행되고, 다크에서의 대비는
  문서의 실측값에 기대고 있습니다
- **화면 이관이 아직입니다.** 이 사이트의 화면 26곳이 프리미티브를 쓰도록 바꿔야 하고,
  그 절차를 `파일:줄` 과 before/after 로 적어 뒀습니다
