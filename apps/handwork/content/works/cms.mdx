## 1. 작업 소개

만든 앱들을 한곳에서 관리하는 대시보드다. 지금은 weather 와 stamp 두 앱이 등록돼 있고, 목록을 데이터로 읽어 오므로 화면은 N개의 앱을 표시할 수 있다.

## 2. 구현 과정과 선택 기준

무엇을 관리할지가 아직 확정되지 않았다. 그래서 이번 범위를 화면과 데이터 경계를 세우는 것으로 한정했다. 포트를 도메인에 고정해 두면 목 데이터에서 Supabase 로 가는 전환이 인프라 한 층 교체로 끝난다.

목록 필터는 URL 검색 파라미터에 남는다. 새로고침해도 유지되고, 계약에 없는 값은 무시하고 전체 목록을 표시한다.

## 3. 현재 상태와 남은 작업

테스트가 없고 그 이유를 README 에 적어 뒀다 — 화면이 확정되기 전이라 회귀 기준을 세울 근거가 없다. Supabase 환경 변수가 없으면 목 데이터로 돌고, 지금 어느 쪽인지는 설정 화면에서 확인된다.
