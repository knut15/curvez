## 1. 무엇을 만들었나

아키텍처를 확정하고 담당 에이전트를 세팅해 팀을 병렬로 돌리는 Claude Code 하네스다. 에이전트 12종·스킬 16종·문서 11편·실행기 8종·훅 5종으로 되어 있다. 저장소 루트가 플러그인 마켓플레이스다.

## 2. 어떤 제약이 있었나

실행 순서를 강제했다. 구현 에이전트는 `.curvez/architecture.md` 의 `## 금지 import` 표를 위반 판정의 **유일한** 근거로 쓴다. 그 파일이 없으면 `blocked` 로 멈추고 아무것도 만들지 않는다.

에이전트 간 통신은 `.curvez/handoff/*.json` 파일이다. 자유 서술이 아니라 `status`·`decisions`·`verification` 같은 칸이 미리 정해져 있어서, 받은 쪽이 `grep` 으로 증거를 찾을 수 있다.

## 3. 무엇이 남았나

커밋 37개. 이 사이트를 포함해 앱 셋이 이 하네스 위에서 돌아간다. 병렬 런타임은 tmux 가 아니라 Claude Code 내장 서브에이전트다.
