## 1. 작업 소개

알바생의 출퇴근을 기록하고 주휴수당을 포함한 급여를 자동으로 계산한다. 사장·매니저·일반 직원의 역할을 구분해 역할별로 볼 수 있는 화면과 데이터를 분리했다.

## 2. 구현 과정과 선택 기준

서버 상태는 TanStack Query, 클라이언트 상태는 Zustand 로 나눴다. 데이터를 관리하는 주체가 서버인지 클라이언트인지를 기준으로 구분했다.

쿼리 키에 `workplaceId` 를 반드시 넣는다. 넣지 않으면 매장을 바꿨을 때 이전 매장 데이터가 남는다. 서버에서 `QueryClient` 를 싱글턴으로 두지 않는 것도 같은 이유다 — 요청 사이에 캐시가 섞이면 남의 급여가 보인다.

## 3. 현재 상태와 남은 작업

커밋 119개, 소스 294개로 이 목록에서 가장 규모가 큰 작업이다. `pnpm verify` 가 타입·계층 규칙·테스트를 CI 와 같은 순서로 돌린다. 배포 주소는 아직 없다.
