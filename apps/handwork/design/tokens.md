# 토큰 — handwork

**값의 실제 출처는 `src/app/globals.css` 다.** 이 문서는 그 값과 *왜 그 값인지*를 적는다.
둘이 다르면 CSS 가 이긴다.

중립 스케일은 라이브러리(`@scopulus/ui/tokens.css`)가 정의하고 **handwork 의 `globals.css` 가
import 뒤에서 덮는다.** 라이브러리는 고치지 않았다 — 그것을 가져다 쓰는 다른 앱까지
중립을 바꿀 이유가 없다.

## 출처

형태와 중립 스케일은 **linear.app 에서 실측했다.** 그 사이트의 렌더 화면에서
`getComputedStyle` 로 읽은 값이고, 눈대중으로 고른 값이 아니다.

| 읽은 것   | 원본 값                             |
| --------- | ----------------------------------- |
| 배경      | `rgb(8, 9, 10)`                     |
| 전경      | `rgb(247,248,248)`                  |
| 카드 면   | `rgb(15, 16, 17)`                   |
| 선        | `rgb(35, 37, 42)`                   |
| muted     | `rgb(138,143,152)`                  |
| 버튼 면   | `rgb(229,229,230)`                  |
| 반경      | `16px`                              |
| 헤딩 굵기 | `510`                               |
| 헤딩 자간 | `-1.408px` (64px 기준 = `-0.022em`) |
| 본문 자간 | `-0.13px` (13px 기준 = `-0.01em`)   |

다크가 원본이고, **라이트는 같은 대비 관계를 뒤집어 맞춘 값이다.**

## 색 — 중립

| 토큰                     | 라이트    | 다크      | 쓰이는 곳               |
| ------------------------ | --------- | --------- | ----------------------- |
| `--background`           | `#ffffff` | `#08090a` | 페이지 바탕             |
| `--foreground`           | `#08090a` | `#f7f8f8` | 본문 글자               |
| `--card`                 | `#fbfbfb` | `#0f1011` | 카드 면                 |
| `--card-foreground`      | `#08090a` | `#f7f8f8` | 카드 안 글자            |
| `--popover`              | `#ffffff` | `#0f1011` | (아직 쓰는 화면 없음)   |
| `--popover-foreground`   | `#08090a` | `#f7f8f8` | 〃                      |
| `--primary`              | `#08090a` | `#e5e5e6` | 주 버튼 면              |
| `--primary-foreground`   | `#ffffff` | `#08090a` | 주 버튼 글자            |
| `--secondary`            | `#f4f5f5` | `#141516` | (아직 쓰는 화면 없음)   |
| `--secondary-foreground` | `#08090a` | `#f7f8f8` | 〃                      |
| `--muted`                | `#f4f5f5` | `#141516` | 태그 칩 바탕            |
| `--muted-foreground`     | `#6b6f76` | `#8a8f98` | 보조 글자 · 비활성 링크 |
| `--accent`               | `#f0f1f1` | `#17181a` | hover 면                |
| `--accent-foreground`    | `#08090a` | `#f7f8f8` | 〃 위 글자              |
| `--border` · `--input`   | `#e6e7e8` | `#23252a` | 1px hairline            |

**카드 면과 배경은 한 단 차이다.** 다크에서 카드가 배경보다 밝고(`#0f1011` > `#08090a`),
라이트에서는 그 관계를 뒤집어 카드가 한 단 어둡다(`#fbfbfb` < `#ffffff`). 같은 색이면
카드가 선 하나로만 서고, 면으로 읽히지 않는다.

**중립을 완전 중립으로 내렸다.** 라이브러리의 중립은 teal 색조를 띠는데(`oklch(… 181.8)`),
사이트 전체가 그 색조 위에 올라가면 브랜드 teal 이 액센트로 읽히지 않는다.

## 색 — 브랜드

| 토큰             | 라이트    | 다크      | 쓰이는 곳                                  |
| ---------------- | --------- | --------- | ------------------------------------------ |
| `--brand-accent` | `#0b6b63` | `#5eead4` | 링크 hover · Cases 점                      |
| `--brand-mark`   | `#f2542d` | `#ff6b4a` | 워드마크의 `a` · 히어로 배지 점 · Works 점 |
| `--brand-canvas` | `#f7f8f8` | `#0f1011` | 헤더 바 면                                 |
| `--brand-ink`    | `#08090a` | `#f7f8f8` | 헤더 바 글자                               |

**코랄만 두 테마의 값이 다른 이유가 따로 있다.** 원색 `#ff6b4a` 는 흰 배경에서 대비 2.82 로,
워드마크가 큰 글자임을 감안한 3:1 에도 못 미쳤다. 그래서 라이트에서만 한 단 내려
`#f2542d`(3.45)로 두고, 다크의 원색은 7.07 이라 그대로 둔다.

**색은 이 둘뿐이다.** 세 영역을 가르는 점도 새 색을 만들지 않고
`--brand-mark`(Works) · `--brand-accent`(Cases) · `--muted-foreground`(Labs)로 쓴다.

**`--brand-overlay-ink` 는 지웠다.** 사진 위에 워드마크를 얹던 시절의 값이고,
히어로가 배경색 위로 옮겨지면서 쓰는 곳이 0곳이 됐다.

## 형태

`--radius: 1rem` (16px). 라이브러리 기본 `0.625rem` 을 덮는다 — 6px 작으면 같은 크기의
면을 놓아도 카드가 아니라 잘린 사각형으로 읽힌다.

| 쓰임                 | 클래스         | 값   |
| -------------------- | -------------- | ---- |
| 카드 · 히어로 프레임 | `rounded-2xl`  | 16px |
| 프레임 안 미니 카드  | `rounded-lg`   | 8px  |
| 버튼 · 배지 · 색 점  | `rounded-full` | pill |
| 태그 칩              | `rounded`      | 4px  |

## 치수

| 토큰                      | 값                 | 무엇                                                                                      |
| ------------------------- | ------------------ | ----------------------------------------------------------------------------------------- |
| `--header-height`         | `3.8125rem` (61px) | 헤더 기본 높이. 헤더가 자기 높이로 쓰고, 상세 화면의 제목 바가 그 아래 붙을 자리로 읽는다 |
| `--header-height-compact` | `3rem` (48px)      | 제목 바가 걸렸을 때의 헤더 높이. 헤더가 이만큼 내주고 그 자리로 제목 바가 내려온다        |

헤더가 전 화면에서 `sticky top-0` 이라 그 아래 붙는 것들이 이 값을 알아야 한다.
**헤더 자신이 이 값을 높이로 갖기 때문에 둘이 어긋날 수 없다.** 61px 은
바 `py-2.5` + 링크 `py-2` + 글자 20px + 아래 선 1px 의 합이다.

주의: 이 값을 `IntersectionObserver` 의 `rootMargin` 에 그대로 넘기면 안 된다 —
`rootMargin` 은 px 과 % 만 받고 `rem` 문자열에는 생성자가 던진다. px 이 필요하면
헤더 요소에서 직접 재라(`src/widgets/site-header.tsx` 가 그렇게 한다).

**그림자를 쓰지 않는다.** 층은 면 색 한 단 차이와 1px 선이 만든다. 그림자를 얹으면
중립 한 단 차이가 묻혀 두 장치가 같은 일을 두 번 한다.

## 타이포

서체는 Pretendard(본문·워드마크) 하나다. Linear 는 Inter 를 쓰는데 Pretendard 가 같은 골격의
한글 확장이라, 굵기와 자간을 같은 값으로 주면 같은 밀도로 앉는다.
모노(`--font-geist-mono`)는 **도면 라벨에만 쓴다.** Flow 절의 `FIG 0.1`~`FIG 0.3` 세 자리가 전부다. 본문·라벨·버튼에는 쓰지 않는다.

| 자리                           | 크기                          | 굵기      | 자간       |
| ------------------------------ | ----------------------------- | --------- | ---------- |
| 워드마크 (히어로)              | `clamp(3.25rem,10vw,6rem)`    | 900       | `-0.04em`  |
| 슬로건                         | `clamp(1.5rem,3.4vw,2.25rem)` | 510       | `-0.022em` |
| 절 제목                        | `clamp(1.75rem,3.4vw,2.5rem)` | 510       | `-0.022em` |
| 세 영역 중심 질문              | `1.0625rem` (17px)            | 510       | `-0.015em` |
| 헤더 로고                      | `0.9375rem` (15px)            | 510       | `-0.015em` |
| 본문 단락                      | `1rem` (16px)                 | 400       | `-0.01em`  |
| 라벨 · 헤더 링크 · 버튼 · 푸터 | `0.8125rem` (13px)            | 510       | `-0.01em`  |
| 카드 설명                      | `0.875rem` (14px)             | 400       | `-0.01em`  |
| 프레임 안 카드 제목            | `0.75rem` (12px)              | 510       | `-0.01em`  |
| 프레임 안 라벨 · 요약          | `0.6875rem` (11px)            | 510 / 400 | `-0.01em`  |
| 프레임 안 메타                 | `0.625rem` (10px)             | 400       | `-0.01em`  |

**굵기는 `font-medium`(500)이 아니라 `font-[510]` 이다.** 실측값이 510 이고, Pretendard 가
가변 폰트라 그 값을 그대로 낼 수 있다.

자간 `-0.01em` 은 `html` 에 전역으로 걸려 있고, 더 큰 글자에서만 더 조인다.

한글은 `break-keep` 으로 낱말 중간에서 꺾이지 않게 한다.

## 상태

| 상태     | 값                                                                          |
| -------- | --------------------------------------------------------------------------- |
| hover    | 면은 `bg-accent`, 글자는 muted → `text-foreground`, 링크는 → `brand-accent` |
| 전이     | `transition-colors duration-150 ease-out` + `motion-reduce:transition-none` |
| focus    | `outline-2 outline-offset-2 outline-ring`, `focus-visible` 에만             |
| active   | 따로 두지 않는다                                                            |
| disabled | 쓰는 자리가 없다                                                            |

| `--border` / `--background`      | 1.24     | 1.30  | 선이라 대비 기준 밖    |

재는 방법: 브라우저에서 `getComputedStyle(document.documentElement)` 로 토큰 hex 를 읽고
WCAG 상대휘도 공식으로 계산한다. `.dark` 클래스를 토글해 같은 계산을 한 번 더 돌린다.

**`--brand-mark` 만 large text 기준(3:1)으로 판정한다.** 쓰이는 자리가 워드마크의 `a` 한 글자
(48px 이상)와 `aria-hidden` 인 색 점뿐이고, `ster` 는 19.93 으로 읽히므로 낱말이 사라지지 않는다.
본문 크기에 이 색을 쓰면 기준이 4.5 로 올라가고 지금 값은 미달이다 — **작은 글자에 쓰지 마라.**
