# 이른둥이 육아 계산기 PRD

> 상태: 확정 · 버전: 4 · 갱신: 2026-10-02

원본은 Claude Docs 문서 [이른둥이 육아 계산기 PRD](https://claude.ai/artifact/8eNRdUuQE7yqNX89vpNXVr)(2026-09-29)다.
이 파일은 그 내용을 앱 저장소로 옮기고, 인터뷰에서 정한 것(스택, 기본 입력)을 더했다.
사이트 이름이 아직 없어서 앱 폴더 이름 `preemie-calc` 는 임시 이름이다.

버전 2 (2026-09-30): kid1004 와 비교한 뒤 사용자가 정한 것을 반영했다. 성장 백분위(F8)와 예방접종 일정(F10)을 이번 범위로 앞당기고, 목표키(F14)·분유량(F15) 계산과 결과 문구 복사(F7 확장)를 더했다. 모든 화면의 본문 폭을 720px 한 열로 맞춘다.

버전 3 (2026-09-30): 프로필 없이 검색으로 들어온 사람이 읽을 공개 가이드를 더했다. 질문형 가이드 6쪽(F16), 가이드 목록 페이지(F17), "어느 나이를 쓰나" 공개판(F18)이다. 원본 Claude Docs 문서의 "유입·SEO 전략"에 있던 질문형 페이지를 버전 1 로 옮길 때 빠뜨렸고, Codex 비교 분석에서 공개 가이드가 부족하다는 지적을 받아 되살렸다.

## 1. 문제

이른둥이 부모는 "지금 이 일에는 어느 나이를 써야 하나"를 계속 묻는다.
성장·발달·수유·이유식은 교정연령을 쓰고, 예방접종과 영유아검진 방문일은 출생연령을 쓴다.
그런데 병원, 보건소, 기관마다 안내가 달라서 부모가 직접 맞춰 봐야 한다.
성장 백분위나 예방접종 계산기는 네이버와 여러 사이트에 이미 있지만, 교정연령을 모든 기능에 같은 방식으로 적용하는 도구는 없다.

| 부모가 자주 묻는 것                | 써야 하는 기준                                                             |
| ---------------------------------- | -------------------------------------------------------------------------- |
| 예방접종은 언제 맞나               | 출생연령                                                                   |
| 영유아검진 문진표는 몇 개월로 쓰나 | 방문 날짜는 출생연령, 문진표와 발달선별검사지는 교정연령 (24개월 검진까지) |
| 이유식은 언제 시작하나             | 교정 6개월 전후, 의료진 상담                                               |
| 교정연령은 언제까지 쓰나           | 보통 24개월, 28주 미만 또는 1.5kg 미만 출생은 36개월까지                   |
| 따라잡기 성장은 되고 있나          | 교정연령 기준 백분위 추이                                                  |
| 본인부담 경감은 언제 끝나나        | 재태기간에 따라 5년 2~4개월                                                |

배경 수치: 37주 미만 출생아 비중은 2010년 5.8%에서 2020년 8.5%로 늘었다([심평원](https://www.hira.or.kr/bbsDummy.do?pgmid=HIRAA020041000100&brdScnBltNo=4&brdBltNo=10640)).
2026년 1월부터 이른둥이 외래 본인부담 경감이 재태기간에 따라 최대 5년 4개월까지 늘었고([쿠키뉴스](https://www.kukinews.com/article/view/kuk202512080005)), 질병관리청은 2027 소아청소년 성장도표 개정을 준비하고 있다([질병관리청](https://kdca.go.kr/kdca/5458/subview.do)).

## 2. 목적

출생일과 출산 예정일을 한 번만 입력하면 성장, 발달, 예방접종, 검진, 지원 제도를 모두 "출생 기준 / 교정 기준"으로 나란히 보여준다.
부모는 기관마다 다른 안내를 맞춰 볼 필요 없이, 결과 옆에 적힌 기준을 보고 바로 쓸 수 있다.
한 번 검색하고 떠나는 사이트가 아니라 아이가 자라는 동안 계속 여는 사이트가 되는 것이 목표다.

## 3. 사용자

1차 사용자는 NICU 퇴원 후 0~36개월 이른둥이를 키우는 부모다. 2차 사용자는 일반 영유아 부모다.
만삭아 부모에게는 교정 칸이 숨겨진, 입력이 하나 적은 도구가 된다.

| 사용자(역할)                                    | 하는 일                                                                                           |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| 32주 출생아 부모 (생후 5개월, 외래 추적관찰 중) | 매일 오늘 교정 며칠인지 확인하고, 주 1회 키·몸무게를 기록해 따라잡기 추이를 본다                  |
| 29주 쌍둥이 부모 (생후 10개월)                  | 겹치는 검진·접종 일정을 보건소·병원 안내와 맞춰 보고, 일정마다 어느 기준인지 한 화면에서 확인한다 |
| 조부모 (돌봄을 나눠 맡음)                       | 부모가 카카오톡으로 보낸 큰 글씨 결과 카드를 본다                                                 |
| 만삭아 부모 (첫 영유아검진 앞둠)                | 개월 수와 접종일을 찾는다. 네이버보다 한 단계 더 정리된 결과를 원한다                             |

로그인과 회원 역할은 없다. 모든 사용자가 같은 기능을 쓴다.

## 4. 핵심 흐름

1. 검색이나 카카오톡 공유 링크로 들어온다.
2. 첫 화면에서 출생일, 출산 예정일, 성별을 입력한다. 출산 예정일을 모르면 출생 주수+일로 바꿔 입력한다.
3. 가입 없이 10초 안에 대시보드가 보인다. 오늘 생후 ○일·○개월과 교정 ○일·○개월이 나란히 나온다.
4. 대시보드에서 "어느 나이를 쓰나" 안내, 영유아검진 도우미, 본인부담 경감 종료일로 이동한다. 각 결과 옆에는 어느 기준을 썼는지가 적혀 있다.
5. 프로필을 기기에 저장한다. 다음에 들어오면 입력 없이 오늘 기준 값이 보인다.
6. 결과를 카드로 만들어 카카오톡으로 가족에게 보낸다.

가장 자주 하는 동작은 셋이다. 오늘 교정일 확인, 다음 검진·접종 날짜 확인, 결과 공유.

## 5. 범위

로드맵은 4단계이고 게이트를 넘으면 다음 단계로 간다. 이번 범위는 1단계다.

| 단계          | 기능                                                                                                                                                                                                      | 다음 단계로 넘어가는 조건 |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------- |
| 1 · MVP       | 아이 프로필, 교정연령 대시보드, "어느 나이를 쓰나" 안내, 영유아검진 도우미, 경감 종료일, 교정 적용 종료 안내, 공유 카드와 문구 복사, 조합형 SEO 페이지, 성장 백분위와 기록, 예방접종 일정, 목표키, 분유량 | 커뮤니티 피드백 반영      |
| 2 · 성장 기록 | 인쇄용 기록                                                                                                                                                                                               | 프로필 저장률 15%         |
| 3 · 접종 일정 | 캘린더 구독, 이유식 시작 안내                                                                                                                                                                             | 2027 성장도표 공표        |
| 4 · 확장      | 2027 성장도표 반영, 만삭아 검색어 확장                                                                                                                                                                    | —                         |

버전 1 에서는 성장 백분위와 기록이 2단계, 예방접종 일정이 3단계였다. 버전 2 에서 1단계로 앞당겼다.

### 이번에 만든다

- 아이 프로필 (여러 아이·쌍둥이 포함) — 모든 기능이 이 입력 하나를 쓴다.
- 교정연령 대시보드 — 경쟁 도구에 없는 핵심 기능이다.
- "어느 나이를 쓰나" 안내 — 부모 질문의 대부분이 여기로 모인다.
- 영유아검진 도우미 — 교정 규칙까지 안내하는 도구가 없다.
- 본인부담 경감 종료일 — 2026년 1월 제도 변경으로 새로 생긴 질문이다.
- 교정연령 적용 종료 안내 — 블로그 설명 수준의 정보만 있다.
- 결과 공유 카드와 문구 복사 — 조부모 등 가족에게 보내는 흐름과 재유입 경로다. 이미지 없이 글로 붙여 넣을 수 있게 결과 문구 복사를 더한다.
- 조합형 SEO 페이지 — 네이버 위젯이 뜨지 않는 긴 검색어를 잡는다.
- 성장 백분위와 기록 — 경쟁 도구에 이미 있지만, 교정연령 자동 적용과 기기 저장으로 차별화한다. 28주 미만 출생아의 교정 40주 이전 구간은 백분위를 보여주지 않고 기록만 남긴다.
- 예방접종 일정 — 출생 기준 일정에 교정 나이를 나란히 적는다.
- 목표키 참고 — 부모 키 평균에 ±6.5cm 를 더하고 뺀 값. 개인 성인 키 예측이 아니라 참고값이라고 표시한다.
- 분유량 참고 — 체중으로 하루 일반 권장량 범위를 보여준다. 이른둥이는 의료진이 정한 양이 있으면 그것을 따르라는 안내를 결과보다 먼저 보여준다.
- 질문형 가이드 6쪽 — §1 표의 질문 6개를 한 쪽씩 공개 페이지로 만든다. 답과 근거, 출처를 보여주고 계산기로 연결한다. 프로필 없이 읽힌다.
- 가이드 목록 페이지 — 질문형 가이드 6쪽과 주수·개월 조합 페이지로 가는 입구다. 지금은 `/guide` 가 비어 있다.
- "어느 나이를 쓰나" 공개판 — 항목별 기준 표를 프로필 없이 보여준다. 내 아이 값은 계산기로 연결한다.

### 이번에 만들지 않는다

- 인쇄용 성장 기록 — 성장 기록이 쌓인 뒤에 쓸모가 있다. 2단계에 붙인다.
- 캘린더 구독 — 출생일이 서버로 가는 문제(미결)가 풀린 뒤 3단계에 붙인다.
- kid1004 의 나머지 기능(월령가이드, 발달체크, 수면, 질환·대처, 병원·약국, 기질검사, 선물추천, 문장 검색) — 이번에 넣지 않기로 했다.
- 이유식 시작 안내 — 우선순위가 가장 낮다(P2). 3단계에 붙인다.
- 회원가입과 서버 저장 — "가입 없이 바로" 원칙과 아이 정보를 기기에만 두는 프라이버시 요구 때문이다.
- 진단이나 판정 문구 — 결과는 참고값으로만 보여준다.

## 7. 성공 기준

1단계 완료 조건:

- 스펙의 1단계 기능(F1\~F8, F10, F13\~F18)의 수용 기준이 모두 통과한다.
- 계산에 쓰는 기준 데이터 파일마다 출처 URL, 기준일, 마지막 확인일이 적혀 있다.
- 첫 방문자가 회원가입 없이 입력을 시작해 대시보드 결과를 보기까지 10초 안에 끝난다 (수동 확인).

출시 후 지표 목표. 아래 값은 가정값이며 첫 3개월 데이터로 다시 맞춘다.

| 지표                      | 정의                                    | 6개월   | 12개월   |
| ------------------------- | --------------------------------------- | ------- | -------- |
| 월 순방문자               | GA 기준 UV                              | 3만     | 15만     |
| 30일 재방문율 (핵심 지표) | 첫 방문 후 30일 안에 다시 온 비율       | 25%     | 35%      |
| 아이 프로필 저장률        | 계산 후 프로필을 저장한 비율            | 15%     | 25%      |
| 공유율                    | 결과 화면에서 카카오톡 공유를 누른 비율 | 5%      | 8%       |
| 캘린더 구독 수            | 예방접종 iCal 구독 누적 (3단계부터)     | 500     | 5,000    |
| 월 광고 수익              | 애드센스 등                             | 20만 원 | 100만 원 |

12개월 목표는 "교정연령" 관련 검색에서 1페이지에 오르고 월 광고 수익 100만 원에 닿는 것이다.
