수용 기준의 예시는 모두 같은 아이를 쓴다. **출생일 2026-03-01, 출산 예정일 2026-04-26** 이다.

## 2. 기능별 동작

### F1. 아이 프로필

- 무엇을 하는가: 이름(선택), 성별, 출생일, 출산 예정일을 한 번 입력받아 기기에 저장한다. 다른 모든 기능이 이 프로필을 쓴다. 기본 입력은 출산 예정일이고, 모르면 출생 주수+일로 바꿔 입력할 수 있다.
- 수용 기준
  - [ ] AC1. 첫 화면에 출생일, 출산 예정일, 성별 입력칸과 버튼만 보인다. 출산 예정일 칸 아래에 "주수로 입력" 전환이 있다.
  - [ ] AC2. 출생일 2026-03-01, 출산 예정일 2026-04-26 을 입력하면 재태기간이 32주 0일로 계산된다.
  - [ ] AC3. 출생일 2026-03-01, 주수 32주 0일을 입력하면 출산 예정일이 2026-04-26 으로 계산돼 AC2 와 같은 프로필이 된다.
  - [ ] AC4. 프로필을 저장하고 페이지를 새로 열면 입력 없이 저장된 프로필로 대시보드가 보인다.
  - [ ] AC5. 프로필을 2개 이상 저장하면 대시보드 위에서 아이를 바꿔 볼 수 있다.
  - [ ] AC6. "정보 전체 삭제"를 누르고 확인하면 저장된 프로필이 모두 사라지고 첫 화면으로 돌아간다.
  - [ ] AC7. 예정일 칸의 라벨은 "원래 출산 예정일"이고, 칸 아래에 "임신 중 병원에서 안내받은 날짜예요. 모르면 '주수로 입력'을 눌러 주세요."가 보인다. (버전 4, 사용자 요청: 출생 뒤에 예정일을 묻는 뜻이 화면에서 드러나지 않음)
- 확인 방법: 자동 테스트 (AC2, AC3는 계산 함수 단위 테스트, AC4~AC6은 E2E)
- 예외
  - 출산 예정일 2026-08-01, 출생일 2026-03-01 처럼 재태기간이 22주 0일 미만이 되면 저장 버튼이 비활성화되고 "날짜를 확인하세요"가 보인다. 44주 초과도 같다.
  - 출생일이 오늘보다 뒤면 같은 방식으로 막는다.
  - 이름을 비워도 저장된다. 목록에는 "아이 1"처럼 번호로 보인다.

### F2. 교정연령 대시보드

- 무엇을 하는가: 오늘 기준 생후 나이와 교정 나이를 나란히 보여준다.
- 수용 기준
  - [ ] AC1. 오늘이 2026-06-01 이면 "생후 92일 · 3개월"과 "교정 36일 · 1개월"이 나란히 보인다.
  - [ ] AC2. 오늘이 2026-04-01 이면 교정 칸에 "교정 D-25"와 "재태 36주 3일"이 보인다.
  - [ ] AC3. 오늘이 2026-06-01 이면 다음 월령일로 "생후 4개월: 2026-07-01"과 "교정 2개월: 2026-06-26"이 보인다.
  - [ ] AC4. 출생일 2026-03-01, 출산 예정일 2026-03-10(재태 38주 5일)이면 교정 칸이 보이지 않고 생후 나이만 보인다.
  - [ ] AC5. 나이 옆에 "생후: 출생일 기준", "교정: 출산 예정일 기준"이 한 줄로 적혀 있다.
- 확인 방법: 자동 테스트 (오늘 날짜를 고정한 단위 테스트)
- 예외: 프로필이 없으면 F1 첫 화면으로 보낸다.

### F3. "어느 나이를 쓰나" 안내

- 무엇을 하는가: 접종, 검진 방문, 문진표, 이유식, 발달 평가마다 어느 기준을 쓰는지와 오늘 그 기준의 값을 보여준다.
- 수용 기준
  - [ ] AC1. 오늘이 2026-06-01 이면 "예방접종 — 출생 기준 — 생후 3개월"이 보인다.
  - [ ] AC2. 같은 날 "이유식 — 교정 기준 — 교정 1개월"이 보인다.
  - [ ] AC3. 같은 날 "영유아검진 방문 — 출생 기준", "문진표·발달선별검사지 — 교정 기준(24개월 검진까지)"이 보인다.
  - [ ] AC4. 항목마다 근거 자료 이름과 기준일이 보인다.
  - [ ] AC5. 재태 37주 이상 아이는 모든 항목이 "생후 나이 그대로"로 보인다.
- 확인 방법: 자동 테스트
- 예외: 없음

### F4. 영유아검진 도우미

- 무엇을 하는가: 검진 차수마다 방문 기간(출생 기준)과 작성할 발달선별검사지 개월(24개월 검진까지 교정 기준)을 보여주고, 문진표의 미숙아 관련 항목을 안내한다.
- 수용 기준
  - [ ] AC1. 차수별 방문 기간은 검진 데이터 파일에 적힌 개월 범위를 출생일에 더한 날짜로 보인다.
  - [ ] AC2. 오늘이 2026-09-15(생후 6개월 14일, 교정 4개월 20일)이면 작성할 검사지가 교정 4개월 기준으로 표시된다.
  - [ ] AC3. 24개월 검진보다 뒤의 차수는 검사지 개월도 출생 기준으로 표시된다.
  - [ ] AC4. 오늘 날짜가 들어가는 차수가 맨 위에 강조돼 보이고, 지난 차수와 남은 차수가 구분된다.
  - [ ] AC5. 화면 아래에 데이터 출처와 기준일이 보인다.
- 확인 방법: 자동 테스트. 규칙 확정은 PRD 미결 1번에 달려 있다.
- 예외: 모든 차수가 지난 아이(생후 72개월 이상)는 "영유아검진 대상 기간이 끝났습니다"가 보인다.

### F5. 본인부담 경감 종료일

- 무엇을 하는가: 재태기간 구간으로 외래 본인부담 경감이 끝나는 날을 계산한다. 구간은 33\~37주 5년 2개월, 29\~33주 5년 3개월, 29주 미만 5년 4개월이다.
- 수용 기준
  - [ ] AC1. 재태 32주 0일이면 "5년 3개월" 구간으로 분류된다.
  - [ ] AC2. 재태 28주 6일이면 "5년 4개월" 구간으로 분류된다.
  - [ ] AC3. 재태 35주 0일이면 "5년 2개월" 구간으로 분류된다.
  - [ ] AC4. 재태 37주 0일 이상이면 "경감 대상이 아닙니다"가 보인다.
  - [ ] AC5. 종료 예정일과 "2026년 1월 시행 제도 기준" 문구가 함께 보인다.
  - [ ] AC6. 재태 33주 0일이면 "5년 2개월" 구간으로 분류된다. (버전 6)
  - [ ] AC7. 재태 29주 0일이면 "5년 3개월" 구간으로 분류된다. (버전 6)
- 확인 방법: 자동 테스트. 종료일 계산 방식(만료일 당일 포함 여부)은 원문을 찾지 못해 "미확정" 표시를 유지한다.
- 예외: 없음

### F6. 교정연령 적용 종료 안내

- 무엇을 하는가: 교정연령을 언제까지 쓰는지 알려준다. 보통 24개월이고, 28주 미만 또는 출생 체중 1.5kg 미만이면 36개월까지 쓸 수 있다.
- 수용 기준
  - [ ] AC1. 재태 32주 0일이고 출생 체중을 입력하지 않았으면 "24개월까지"와 "출생 체중이 1.5kg 미만이면 36개월까지"가 보인다.
  - [ ] AC2. 재태 27주 6일이면 "36개월까지 쓸 수 있음"이 보인다.
  - [ ] AC3. 재태 32주 0일, 출생 체중 1.4kg 이면 "36개월까지 쓸 수 있음"이 보인다.
  - [ ] AC4. 안내 아래에 "의료진과 상담해 정하세요"가 보인다.
- 확인 방법: 자동 테스트
- 예외: 재태 37주 이상이면 이 기능이 보이지 않는다.

### F7. 결과 공유 카드와 문구 복사

- 무엇을 하는가: 지금 보는 결과를 큰 글씨 이미지 카드로 만들고 카카오톡 공유 링크를 만든다. 결과를 글로 붙여 넣을 수 있게 결과 문구도 복사할 수 있다.
- 수용 기준
  - [ ] AC1. 이름을 "하늘"로 저장한 프로필의 공유 링크 URL과 카드 이미지에 "하늘"이 들어가지 않는다.
  - [ ] AC2. 공유 링크를 다른 기기에서 열면 같은 날짜 기준으로 같은 결과가 보인다.
  - [ ] AC3. 공유 링크에는 계산에 필요한 값(출생일, 출산 예정일)만 들어간다.
  - [ ] AC4. 수동 확인: 360px 폭 휴대폰에서 받은 카드를 확대하지 않고 숫자를 읽을 수 있다.
  - [ ] AC5. 오늘이 2026-06-01 일 때 "결과 문구 복사"를 누르면 클립보드에 "생후 92일 · 3개월", "교정 36일 · 1개월"과 공유 링크가 담긴 문구가 들어간다.
  - [ ] AC6. AC5 의 문구에 저장된 이름("하늘")이 들어가지 않는다.
  - [ ] AC7. 복사가 끝나면 "문구를 복사했어요"가 보인다.
- 확인 방법: AC1\~AC3, AC5\~AC7 자동 테스트, AC4 수동 확인
- 예외: 카카오톡 공유를 쓸 수 없는 환경(데스크톱 브라우저 등)에서는 링크 복사 버튼이 보인다.

### F8. 성장 백분위 + 기록

- 무엇을 하는가: 측정일, 키, 몸무게, 머리둘레, 측정 자세를 기록하고 백분위와 추이 그래프를 보여준다. 이른둥이는 교정연령을 자동으로 적용한다.
- 수용 기준
  - [ ] AC1. 재태 37주 미만 아이의 백분위는 측정일의 교정 나이로 계산되고, 결과 옆에 "교정 ○개월 기준"이 보인다.
  - [ ] AC2. 백분위가 3 미만이거나 97 초과면 "소아청소년과 상담을 권합니다"가 보인다.
  - [ ] AC3. 기록이 2개 이상이면 측정일 순서로 추이 그래프가 그려진다.
  - [ ] AC4. 같은 입력의 백분위가 공공데이터포털 백분위수 기준 표와 소수점 첫째 자리까지 같다.
- 확인 방법: 자동 테스트
  - [ ] AC5. 재태 27주 0일 아이의 측정일이 출산 예정일보다 앞서면(교정 40주 이전) 백분위 대신 "이 시기는 백분위를 표시하지 않습니다"가 보이고, 기록은 저장된다.
- 예외: 재태 28주 이상 이른둥이도 측정일이 출산 예정일보다 앞서면 AC5 와 같이 백분위를 보여주지 않는다. 성장도표가 출산 예정일(교정 0일)부터 시작하기 때문이다.

### F9. 인쇄용 성장 기록 (2단계)

- 예외: 기록이 없으면 인쇄 버튼이 비활성화된다.

### F10. 예방접종 일정

- 수용 기준

  - [ ] AC2. 완료 체크한 접종은 "완료", 권장일이 7일 이내로 남은 접종은 "임박", 권장일이 지나고 체크하지 않은 접종은 "놓침"으로 보인다.
  - [ ] AC3. 완료 체크는 새로 열어도 유지된다.
- 확인 방법: 자동 테스트
- 예외: 없음

- 예외: 구독 URL을 만들려면 캘린더 앱이 서버에 출생일을 보내게 된다. PRD 미결 7번이 정해질 때까지 착수하지 않는다.

- 예외: 없음

### F13. 주수·개월 조합 SEO 페이지

- 무엇을 하는가: 출생 주수(24주부터 36주까지) × 생후 개월(0개월부터 36개월까지) 조합마다 교정연령과 그 시점의 검진·접종·기준 안내를 담은 정적 페이지를 빌드 때 만든다. 13 × 37 = 481쪽이다. 원본 문서의 "약 400쪽"보다 많다.
- 수용 기준

  - [ ] AC2. "32주 출생 생후 3개월" 페이지에 "예정일보다 8주 일찍 태어남"과 교정 나이 설명이 보인다.
  - [ ] AC3. 각 페이지에 계산기로 가는 링크가 있고, 누르면 해당 주수가 미리 채워진 입력 화면이 열린다.

- 예외: 이번 버전에서는 검진 안내만 넣는다. 접종 안내를 조합 페이지에 넣는 것은 정하지 않았다.

### F14. 목표키 참고

- 무엇을 하는가: 아빠 키와 엄마 키, 아이 성별로 목표키 참고 범위를 보여준다. 개인의 성인 키 예측이 아니다.
- 수용 기준
  - [ ] AC1. 아빠 175cm, 엄마 162cm, 남아면 "목표키 참고 175.0cm (168.5~181.5cm)"가 보인다.
  - [ ] AC2. 아빠 175cm, 엄마 162cm, 여아면 "목표키 참고 162.0cm (155.5~168.5cm)"가 보인다.
  - [ ] AC3. 결과 아래에 "부모 키로 계산한 참고값이며 성인 키 예측이 아닙니다"와 계산식 출처가 보인다.
- 확인 방법: 자동 테스트
- 예외: 부모 키 중 하나라도 비었거나 100cm 미만·230cm 초과면 계산 버튼이 비활성화되고 "부모님 키를 모두 확인하세요"가 보인다.

### F15. 분유량 참고

- 무엇을 하는가: 아이 체중으로 하루 분유량 일반 권장 범위를 보여준다. 계수는 데이터 파일에 두고 출처를 함께 적는다.
- 수용 기준
  - [ ] AC1. 데이터 파일의 계수가 하루 체중 1kg당 a\~b ml 이면, 체중 4.0kg 에서 "하루 4a\~4b ml"가 보인다.
  - [ ] AC2. 재태 37주 미만 아이는 결과보다 먼저 "의료진이 정해 준 양이 있으면 그 양을 따르세요"가 보인다.
  - [ ] AC3. 결과 아래에 계수의 출처와 기준일, "참고용이며 진단을 대신하지 않음"이 보인다.
- 확인 방법: 자동 테스트
- 예외

## 4. 도메인 규칙

교정일수:

```
교정일수 = 생후일수 − (280 − 출생 재태일수)
```

- 출산 예정일을 입력하면 교정일수는 예정일로부터 지난 날수다. 주수를 입력하면 40주(280일)를 기준으로 예정일을 역산한다.
- 생후일수는 출생일 당일을 0일로 센다 (PRD 가정).
- 개월 수는 달력 기준 만 개월이다. 2026-03-01 생은 2026-06-01 에 3개월이 된다 (PRD 가정).
- 재태 37주(259일) 이상 출생이면 교정 표시를 숨긴다.
- 교정일수가 음수면 "교정 D-○"와 오늘 기준 재태주수 ○주 ○일로 표시한다.
- 날짜는 한국 시간(KST) 기준으로 계산한다 (PRD 가정).

나이 기준:

| 항목                         | 기준                       |
| ---------------------------- | -------------------------- |
| 예방접종                     | 출생연령                   |
| 영유아검진 방문              | 출생연령                   |
| 문진표·발달선별검사지        | 교정연령 (24개월 검진까지) |
| 성장 백분위·발달·수유·이유식 | 교정연령                   |

목표키 (F14):

```
남아: (아빠 키 + 엄마 키 + 13) ÷ 2,  범위 ±6.5cm
여아: (아빠 키 + 엄마 키 − 13) ÷ 2,  범위 ±6.5cm
```

분유량 (F15):

```
하루 권장량 = 체중(kg) × 계수 하한 ~ 체중(kg) × 계수 상한  (ml)
```

- 분유량은 교정 나이로 적용 월령 범위를 판정한다.
- 목표키는 Tanner 공식으로 표기한다. 분유량 계수는 0~3개월만 확인됐고 4개월 이후는 "확인 중"이다 (PRD §9 2026-09-30 결정).
