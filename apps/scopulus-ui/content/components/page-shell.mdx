import { PageShell } from "@scopulus/ui";

서브 페이지의 바깥 컨테이너입니다. 폭·좌우 여백·세로 여백을 한 자리에 모읍니다.

```tsx
<PageShell>
  <PageTitle>케이스</PageTitle>
  <ul>{/* ... */}</ul>
</PageShell>
```

이 페이지도 `PageShell` 안에 들어 있습니다. 폭이 1024px 에서 멈추고 가운데 정렬되는 것,
좁은 화면에서 좌우 여백이 20px 인 것이 그 결과입니다.

## 근거 — 같은 클래스가 다섯 번

```
mx-auto w-full max-w-5xl flex-1 px-5 py-10 md:px-8 md:py-16
```

다섯 파일에서 **한 글자도 다르지 않게** 반복됐습니다. 그것이 이 컴포넌트가 존재하는 이유의
전부입니다.

## 값을 받지 않는다

`className` 도 `as` 도 받지 않습니다.

**덧붙일 구멍을 열면** 여섯 번째 값이 생기고 어느 페이지가 표준인지 판정할 근거가 사라집니다.
다른 여백이 필요한 화면은 이것을 쓰지 않는 화면입니다 — 배경 사진이 화면을 가득 채우는 랜딩이
그렇습니다.

항상 `<main>` 을 렌더합니다. 한 문서에 `<main>` 은 하나여야 하는데, 태그를 고를 수 있게 하면
둘이 생길 수 있습니다.

## `flex-1` 이 절반이다

`<body class="flex min-h-full flex-col">` 의 남은 높이를 먹습니다. 본문이 짧아도 푸터가 화면
아래에 붙습니다. 빼면 내용이 적은 페이지에서 푸터가 떠오릅니다.
