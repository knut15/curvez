## 트리거의 이름은 aria-labelledby 로만 온다

트리거는 `role="combobox"` 입니다. **combobox 는 안쪽 글자가 접근 이름이 되지 못하는
role 입니다.** 트리거에 "공개" 라고 떠 있어도 이름은 비어 있고, 그러면 접근성 검사가
`aria-input-field-name` 으로 잡습니다.

Base UI 는 이름을 `Field` 컨텍스트나 `Select.Label` 에서만 찾습니다. **`<label htmlFor>` 는
보지 않습니다** — [Checkbox](/components/checkbox) 나 [Input](/components/input) 에서 통하는
방법이 여기서는 통하지 않습니다.

```tsx
<span id="scope-label">공개 범위</span>
<Select>
  <SelectTrigger aria-labelledby="scope-label">
    <SelectValue placeholder="고르세요" />
  </SelectTrigger>
  …
</Select>
```

## items 를 주지 않으면 원본 값이 보인다

`SelectValue` 는 고른 항목의 **값**을 보여줍니다. `value="public"` 을 고르면 트리거에
`public` 이 뜹니다. 라벨을 보이게 하려면 `Select` 에 `items` 를 주십시오.

```tsx
<Select items={{ public: "공개", unlisted: "링크 아는 사람만", private: "비공개" }}>
```

`SelectItem` 의 children 과 `items` 의 라벨을 **두 곳에 적게 됩니다.** 한 곳에서 만들어
양쪽에 흘리는 편이 어긋나지 않습니다 — 위 예제도 같은 객체에서 항목을 펼쳐 씁니다.

## 목록은 트리거 폭을 따라간다

목록 폭이 `w-(--anchor-width)` 라 트리거와 같아지고, 최소 `min-w-36` 입니다
(`select.tsx:84`). 긴 항목은 잘리지 않고 가로로 넘칩니다 — 트리거 폭을 항목에 맞춰
잡으십시오.

`alignItemWithTrigger` 기본값이 `true` 라 (`select.tsx:63`) **고른 항목이 트리거 위에
겹쳐 뜹니다.** 네이티브 `select` 와 같은 움직임인데, 목록이 길면 화면 위아래로 밀려나므로
위치를 예측하기 어렵습니다. 아래로 펼치게 하려면 `alignItemWithTrigger={false}` 를 주십시오.

## 항목은 Group 으로 감싼다

여백은 `SelectGroup` 이 갖고 있습니다 (`p-1`). `SelectContent` 는 children 을 그대로
`List` 에 넣으므로 (`select.tsx:90`), 그룹 없이 `SelectItem` 만 넣으면 **항목이 면 가장자리에
붙습니다.** 그룹이 하나뿐이어도 감싸십시오.
