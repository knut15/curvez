## 크기를 갖고 있지 않다

`Skeleton` 은 바탕색 · 둥근 모서리 · 맥박 세 가지만 갖습니다. **높이도 폭도 없습니다** —
`className` 으로 주지 않으면 높이 0 인 요소가 되어 화면에 아무것도 보이지 않습니다.

```tsx
<Skeleton className="h-5 w-48" />
```

자리마다 크기가 다르기 때문에 컴포넌트가 정하지 않습니다. **그 대신 쓰는 쪽이 매번 값을
적어야 합니다.**

## 실제 내용과 같은 크기로 맞춘다

이것이 이 컴포넌트를 쓰는 유일한 요령입니다. 자리가 어긋나면 내용이 도착하는 순간 화면이
튀고, **그 튐은 기다림 자체보다 눈에 띕니다.**

- 글줄에는 실제 글자 높이(`h-4` · `h-5`)를 주고, 마지막 줄만 짧게(`w-2/5`) 잘라 문단처럼 보이게 합니다
- [Badge](/components/badge) 자리에는 `rounded-full` 을 더합니다
- [Card](/components/card) 자리에는 카드와 같은 테두리 · 여백 · 간격을 그대로 씁니다

위 예제가 그 방식입니다 — 카드 한 장이 들어올 자리를 카드와 같은 `p-4` · `gap-4` 로 짰습니다.

## 화면 낭독기에는 아무 말도 하지 않는다

`role` 도 `aria-label` 도 붙이지 않습니다. 모양만 있는 자리 표시라 읽을 것이 없습니다.

**기다리는 중이라는 사실을 전해야 하면 감싸는 쪽에서 말하십시오.** 바깥 영역에
`aria-busy="true"` 를 주거나, 로딩이 끝났을 때 결과를 [Alert](/components/alert) 로
알리는 편이 맞습니다.

`animate-pulse` 는 Tailwind 의 기본 애니메이션이라 `prefers-reduced-motion` 을 따로 보지
않습니다. 움직임을 줄여야 하는 자리라면 `motion-reduce:animate-none` 을 붙이십시오.
