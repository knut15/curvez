## scope 는 직접 준다

`TableHead` 는 `<th>` 를 내지만 `scope` 를 붙이지 않습니다. **머리글이 한 행뿐이면 브라우저가
열 머리글로 추론하지만, 행 머리글이 섞이거나 머리글이 두 줄이면 추론이 갈립니다.**

```tsx
<TableHead scope="col">제목</TableHead>
```

`props` 가 그대로 흘러가므로 붙이면 됩니다. 빈 `<th>` 는 만들지 마십시오 — 체크박스 열처럼
보이는 글자가 없어야 하는 자리라면 `className="sr-only"` 로 이름을 숨겨서 넣으십시오.

## 감싸개가 가로 스크롤을 가져간다

`Table` 은 `<table>` 하나가 아니라 **`overflow-x-auto` 인 `<div>` 로 한 겹 감싼 것**입니다
(`table.tsx:10`). 좁은 화면에서 표만 가로로 밀리고 페이지 전체는 밀리지 않습니다.

셀이 `whitespace-nowrap` 이라 **글자가 줄바꿈되지 않고 표가 옆으로 늘어납니다.** 긴 글이
들어가는 열은 해당 셀에 `whitespace-normal` 을 주십시오.

## 캡션은 표 아래에 붙는다

`TableCaption` 은 `caption-bottom` 이라 화면에서는 표 아래에 보입니다. **DOM 순서는
`<table>` 의 첫 자식이어야 합니다** — HTML 이 `<caption>` 의 위치를 그렇게 정해 두었고,
화면 낭독기도 그 순서로 읽습니다.

```tsx
<Table>
  <TableCaption>최근 사례 3건</TableCaption>
  <TableHeader>…</TableHeader>
</Table>
```

## 정렬과 선택은 없다

`data-[state=selected]` 에 걸린 바탕색은 있지만 **그 상태를 만드는 것은 이 컴포넌트가
아닙니다.** 정렬 · 선택 · 페이지 나누기는 부르는 쪽이 갖습니다. 표는 값을 화면에 놓는
것까지만 합니다.
