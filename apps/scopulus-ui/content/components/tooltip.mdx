import {
  Button,
  Tooltip,
  TooltipContent,
  TooltipProvider,
  TooltipTrigger,
} from "@scopulus/ui";

가리킨 것의 이름을 짧게 말합니다. 한 줄을 넘기면 그것은 툴팁이 아니라
[Popover](/components/popover) 입니다.

<div className="flex flex-wrap items-center gap-3 not-prose my-6">
  <TooltipProvider>
    <Tooltip>
      <TooltipTrigger render={<Button variant="outline" />}>
        발행 취소
      </TooltipTrigger>
      <TooltipContent>공개 주소가 즉시 사라집니다</TooltipContent>
    </Tooltip>
    <Tooltip>
      <TooltipTrigger
        render={<Button variant="ghost" size="icon" aria-label="사례 지우기" />}
      >
        ●
      </TooltipTrigger>
      <TooltipContent>사례 지우기</TooltipContent>
    </Tooltip>
  </TooltipProvider>
</div>

## TooltipProvider 가 없으면 동작하지 않는다

`Tooltip` 하나만 놓으면 뜨지 않습니다. 여러 툴팁이 지연 시간을 공유하는 곳이 프로바이더라,
**앱 루트에 한 번 두어야 합니다.**

```tsx
// app/layout.tsx
<TooltipProvider>{children}</TooltipProvider>
```

기본 `delay` 는 `0` 입니다 (`tooltip.tsx:7`) — 올리면 바로 뜹니다. 프로바이더에 값을 주면
그 아래 전부에 적용됩니다.

스토리북에는 그 루트가 없어서 데코레이터에서 감쌌습니다. 위 예제도 같은 이유로
`TooltipProvider` 를 예제 안에 두고 있습니다.

## 툴팁이 이름을 대신하지 않는다

아이콘만 있는 버튼이 툴팁의 본래 자리인데, **툴팁을 달았다고 `aria-label` 을 빼면
안 됩니다.**

```tsx
<TooltipTrigger render={<Button variant="ghost" size="icon" aria-label="사례 지우기" />}>
  <Trash2Icon aria-hidden />
</TooltipTrigger>
<TooltipContent>사례 지우기</TooltipContent>
```

툴팁은 포인터를 올리거나 포커스가 가야 뜹니다. **버튼 목록을 훑기만 하는 사람에게는 그
글자가 존재하지 않는 것과 같습니다.** 빠지면 접근성 검사가 `button-name` 으로 잡습니다.

같은 말을 두 곳에 적게 되는데, 그것이 맞습니다 — 하나는 항상 있는 이름이고 하나는 가리켰을
때의 설명입니다. 설명이 이름보다 길어진다면 툴팁이 아니라 도움말이 필요한 자리입니다.

## 색이 본문과 뒤집혀 있다

바탕이 `--foreground`, 글자가 `--background` 입니다. 페이지의 본문과 정확히 반대라, 어느
테마에서도 떠 있는 면으로 읽힙니다. 화살표도 같은 색을 씁니다.

폭 상한은 `max-w-xs` 입니다 (`tooltip.tsx:52`). 넘으면 줄바꿈되는데, **두 줄이 넘어가면
툴팁으로 쓸 내용이 아닙니다.**

## 눌러서 여는 것이 아니다

`Tooltip` 은 hover 와 focus 로만 열립니다. 터치 화면에는 hover 가 없으므로 **모바일에서는
사실상 보이지 않습니다.** 터치로도 읽혀야 하는 내용이면 [Popover](/components/popover) 로
옮기거나, 화면에 그냥 적으십시오.
