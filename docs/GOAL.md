# GOAL — city-presets : 브라우저에서 도는 도시 색 필터

> 이 문서는 city-presets 제작의 단일 기준이다. 결정된 사항은 확정으로 취급하고 되묻지 않는다.
> 제품의 배경과 근거는 Obsidian 볼트의 `Studio-Curvez/아이디어/도시 필터 — 사진 한 장을 열두 가지 무드로.md` 가 정본이다.

---

## 0. 한 줄 목표

사용자가 **자기 사진 한 장에 도시 이름의 색 하나를 걸어 받아 가는 웹 도구**를 만든다.

사용자가 하는 일은 넷뿐이다 — 사진을 고른다, 도시를 고른다, 색이 걸린다, 받는다.
라이트룸을 깔 필요도, 프리셋 파일을 가져올 필요도, 값을 옮겨 적을 필요도 없다.

**도시 이름은 찍을 장소가 아니라 색의 이름이다.** 삿포로는 삿포로에서 찍은 사진이 아니라,
어디서 찍었든 겨울 맑은 날의 공기로 보이게 만드는 색이다.

---

## 1. 확정 사항 (변경 금지)

| 항목 | 결정 |
| --- | --- |
| 처리 위치 | **브라우저 안에서만.** 사진은 사용자 기기 밖으로 나가지 않는다. 폰에서도 같다 |
| 연산 | **WebGL 셰이더.** 폰 사진이 1,200만 화소라 메인 스레드 자바스크립트로는 화면이 멈춘다 |
| 값의 정본 | `grade.py` 의 `PRESETS`. 브라우저 구현은 이 값을 옮겨 담기만 한다 |
| 색 개수 | **12종.** 늘리지도 줄이지도 않는다 |
| 값 보호 | **하지 않는다.** 난독화도, 값을 숨기는 설계도 하지 않는다 |
| 받는 것 | 기본은 **색이 걸린 사진 한 장, 원본 해상도 그대로.** 흰 테두리에 값이 붙은 버전은 선택 |
| 언어 | 화면 문구·주석·커밋 전부 한글. 슬라이더 약어와 도시 이름은 영문 |

**값 보호를 하지 않는 이유:** 브라우저에서 다 도는 이상 값은 사용자 기기 안에 있다. 서버로 안
보내기로 한 이상 원리상 막을 수 없고, 막으려 들면 코드만 복잡해지고 정작 쓰는 사람이 느려진다.
가져갈 사람은 가져가게 둔다.

---

## 2. 먼저 해야 하는 일 — 파이썬을 옮길 수 있는 형태로 고친다

`grade.py` 의 연산 중 **세 군데가 언어를 건너면 달라진다.** 값은 그대로 두고 연산만 고친다.
이 작업이 브라우저 구현보다 앞선다.

| 갈리는 곳 | 무엇을 한다 | 안 고쳤을 때 차이(리스본 실측) |
| --- | --- | --- |
| 가우시안 블러 | 커널을 명시해 파이썬과 셰이더가 같은 것을 쓰게 한다. 브라우저 기본 `filter: blur()` 를 쓰지 않는다 | 평균 0.432 · 최대 23 · 픽셀 7.14% 가 1레벨 초과 |
| 그레인 난수 | numpy 시드를 버리고 **픽셀 좌표 해시 기반 노이즈**로 양쪽을 바꾼다 | 평균 2.81 · 픽셀 71.7% 가 다름 |
| HSV 변환 | 파이썬 쪽도 정수 0–255 색상환 대신 **실수 HSV** 로 바꾼다 | 미세하게 다름 |

비트 깊이는 손대지 않아도 된다. 입력을 8비트로 깎아 돌려도 평균 차이 0.000 · 최대 0 이었다.

**고친 뒤 결과가 바뀌면 안 된다.** 고치기 전 열두 장을 기준으로 잡고, 고친 뒤 픽셀 차이가
아래 기준 안인지 확인한다. 넘으면 값이 아니라 연산을 잘못 옮긴 것이다.

---

## 3. 같은 결과인지 판정하는 법 (이 기준으로만 통과시킨다)

| 지표 | 통과 기준 |
| --- | --- |
| 평균 절대차 | **0.5 레벨 미만** |
| 1레벨 초과 픽셀 비율 | **1% 미만** |
| 최대 차이 | 참고값으로 기록한다. 단독으로는 판정하지 않는다 |

- 대상은 `base/` 여섯 장 × 12 프리셋 = 72장 전수다. 표본을 고르지 않는다
- 블러와 그레인을 쓰지 않는 프리셋(서울·산토리니 등)은 **평균 0.000** 이 나와야 한다. 완전히 결정적인 연산이라 그렇다. 0.000 이 아니면 다른 곳이 틀린 것이다
- 눈으로 보는 확인이 수치를 대신하지 못하고, 수치가 눈을 대신하지도 못한다. 둘 다 한다

---

## 4. 열두 개가 서로 갈리는지도 계속 잰다

같은 사진에 걸었을 때 두 개가 비슷하면 그것은 열두 개가 아니라 열 개다.

열두 개에서 나오는 짝은 66개다. 각 결과의 **R−B 차 · G−B 차 · 평균 채도 · 평균 밝기** 네 값으로
짝마다 거리를 재면 붙은 짝이 목록 맨 위로 올라온다.

| | 값 |
| --- | --- |
| 현재 최소거리 | 여섯 원본 전부에서 **20.8 이상** |
| 현재 중앙값 | 61.9 ~ 83.3 |
| 통과 기준 | 어느 원본에서도 **최소거리 20 아래로 떨어지지 않는다** |

**값을 고치면 반드시 다시 잰다.** 한 프리셋을 밀면 다른 프리셋과 붙는다. 실제로 세 번 그랬다.

> 📌 **수치는 보수적이다**: 평균 기반이라 색의 방향이 반대인 짝도 가깝게 나온다.
> 20 근처인 짝은 눈으로 다시 본다.

## 5. 화면

한 화면으로 끝낸다. 단계를 나누지 않는다.

| 영역 | 하는 일 |
| --- | --- |
| 사진 넣기 | 파일 고르기와 끌어 놓기. **업로드가 아니라 읽기다** — 그 사실을 화면에 적는다 |
| 미리보기 | 고른 색이 걸린 상태로 크게 보인다. 원본과 비교할 수단을 준다 |
| 도시 고르기 | 열두 개. 각각 이름과 무드 한 줄. 지금 걸린 것이 무엇인지 늘 보인다 |
| 받기 | 사진 한 장. 테두리·값 버전은 선택 |

**상태 네 가지를 전부 그린다.** 사진을 넣기 전, 계산 중, 다 된 뒤, 실패했을 때.
실패는 지원하지 않는 파일 형식과 너무 큰 사진 둘이다.

## 6. 빌드 순서

1. **파이썬을 옮길 수 있는 형태로 고친다** (2절). 고치기 전 열두 장을 기준으로 남긴다
2. **비교 도구를 먼저 만든다** — 두 이미지의 평균 절대차와 1레벨 초과 비율을 내는 것. 3절 기준을 기계가 판정하게 한다
3. **블러·그레인을 안 쓰는 프리셋 하나를 셰이더로 옮긴다.** 완전히 결정적이라 0.000 이 나와야 하고, 안 나오면 구조가 틀린 것이다
4. **나머지 열한 개를 옮긴다.** 블러와 그레인이 마지막이다
5. **72장 전수 판정.** 3절 기준을 넘기면 다음으로 가지 않는다
6. **화면을 붙인다** (5절)
7. **받기를 붙인다**

**3번을 건너뛰지 마라.** 열두 개를 한꺼번에 옮기고 나서 차이가 나면, 값이 틀렸는지 연산이
틀렸는지 어느 프리셋에서 틀렸는지 분리되지 않는다.

## 7. 완료 기준

- [ ] 72장 전수에서 평균 절대차 0.5 미만 · 1레벨 초과 픽셀 1% 미만
- [ ] 블러·그레인을 안 쓰는 프리셋은 평균 **0.000**
- [ ] 66쌍 최소거리가 여섯 원본 전부에서 20 이상
- [ ] 1,200만 화소 사진을 폰 브라우저에서 걸었을 때 화면이 멈추지 않는다
- [ ] 네트워크 탭에 사진이 나가는 요청이 **0건**
- [ ] 상태 네 가지가 전부 그려져 있다
- [ ] 받은 사진의 해상도가 원본과 같다

**마지막 두 줄 전에 멈추지 마라.** 사진이 안 나간다는 것이 이 도구의 존재 이유이고,
그것은 주장이 아니라 네트워크 탭으로 확인하는 사실이다.

---

## 8. 하지 않는 것

- **서버로 사진을 보내는 것** — 임시 저장도, 썸네일 생성도 하지 않는다
- **자동 보정·추천** — 고르는 것이 이 도구의 핵심이다. 자동으로 골라 주면 열두 개를 만들 이유가 없다
- **값 보호** — 난독화, 값 분할, 워터마크로 막기
- **색 개수 늘리기** — 열두 개로 고정이다. 하나를 더하면 붙는 짝이 생긴다
- **필름 이름 쓰기** — 상표 문제도 있고 검증도 못 한다
- **촬영 정보 지어내기** — ISO·렌즈·셔터는 실제 값이 아니다. 형식상 필요하면 `GRAIN 14 ≈ISO 800` 처럼 "상당" 으로 적는다

## 9. 아직 정하지 않은 것

이 셋은 확정이 아니다. 정해지기 전까지 코드에 가정을 심지 않는다.

| 미결 | 정해지면 바뀌는 것 |
| --- | --- |
| 유료 여섯 개를 어떻게 가르나 | 결제·인증이 붙는다. 값 보호는 어느 쪽이든 하지 않는다 |
| 어디에 올리나 | handwork 안의 라우트 하나인지 별도 도메인인지 |
| 묶음 이름 | 값 스트립에 임시로 `CITY FILTER 12` 가 들어가 있다 |
