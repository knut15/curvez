# component: Avatar

purpose: 사람이나 사물 하나를 가리키는 작은 원형 그림. 그림이 없으면 이름에서 만든 이니셜이 선다

## 근거 — daisyUI 와 shadcn 에서 구조만 옮겼다

### 1. 이 값은 화면에서 센 값이 아니다

**handwork 화면 사용처: 0곳.** 이 컴포넌트는 화면에 한 번도 나온 적이 없다.
기존 9종의 `## 근거` 에 있는 `파일:줄` 표가 이 문서에는 **없다.** 지어낼 수 없어서 비운 것이지
찾다 만 것이 아니다. 값의 출처는 아래 두 벤더와 [`../tokens.md`](../tokens.md) 뿐이다.

| 항목           | 값                                                                        |
| -------------- | ------------------------------------------------------------------------- |
| 참고한 곳 1    | daisyUI Avatar — <https://daisyui.com/components/avatar/>                 |
| 참고한 곳 2    | shadcn/ui Avatar — <https://ui.shadcn.com/docs/components/avatar>         |
| 옮긴 날짜      | **2026-09-12**                                                            |
| 옮긴 것        | 마크업 구조 하나 — 원형 껍데기 안에 `<img>` 또는 글자                     |
| 옮기지 않은 것 | 클래스 이름 전부. daisyUI 의 `avatar`·`avatar-placeholder` 를 쓰지 않는다 |

**클래스는 우리 토큰으로 다시 썼다.** daisyUI 는 `bg-neutral text-neutral-content` 를 쓰는데
이 시스템에는 `--neutral` 이 없다. `--muted` / `--muted-foreground` 로 바꿨고, 그 쌍은
[`../tokens.md`](../tokens.md) 의 `## 대비 검증` 에 이미 있는 쌍이다(칩 글자/칩 배경).
**새 대비 쌍을 만들지 않았다.**

### 2. 두 벤더가 다른 곳과 고른 쪽

| 갈래                | daisyUI                          | shadcn/ui                                       | 우리                |
| ------------------- | -------------------------------- | ----------------------------------------------- | ------------------- |
| 조각 수             | 껍데기 + 안쪽 `div` 2겹          | `Avatar` · `AvatarImage` · `AvatarFallback` 3개 | **1개**             |
| 이니셜 대체         | `avatar-placeholder` 클래스 토글 | `AvatarFallback` 을 따로 넣는다                 | `src` 유무로 나뉜다 |
| 로딩 실패 시 물러섬 | 없다                             | 있다(상태를 갖는다)                             | **없다**            |
| 묶음(group)         | `avatar-group`                   | `AvatarGroup` · `AvatarGroupCount`              | **만들지 않았다**   |

**조각을 셋으로 나누지 않았다. 이유:** shadcn 이 셋으로 나눈 까닭은 그림 로딩 실패를 상태로
잡아 대체물로 물러서기 위해서다. 그 상태를 가지려면 `"use client"` 가 붙는다. 이 18종은
상태·포털 없이 마크업과 토큰만으로 되는 것을 고른 묶음이라 전제가 다르다.

**묶음(겹쳐 놓은 여러 얼굴)을 만들지 않았다. 이유:** 겹치려면 각 얼굴에 바탕색 테두리를 둘러
서로를 잘라 내야 하고, 그러려면 `className` 을 열어야 한다. 쓸 자리가 0곳인 지금
구멍을 먼저 여는 셈이다. 필요해지면 그때 `AvatarGroup` 을 따로 만든다.

### 3. 왜 Data display 묶음에 들어가는가

이 묶음은 **값을 보여 주기만 하고 받지 않는** 것들이다. `Avatar` 는 그중 사람을 가리키는 자리다.

## props

| 이름 | 타입                      | 필수 | 기본값    | 의미                                             |
| ---- | ------------------------- | ---- | --------- | ------------------------------------------------ |
| name | `string`                  | O    | —         | 누구인지. `alt` 와 이니셜과 `aria-label` 에 쓴다 |
| src  | `string`                  | X    | —         | 그림 주소. 없으면 이니셜이 선다                  |
| size | `sm` \| `default` \| `lg` | X    | `default` | 지름. 아래 표의 세 값뿐이다                      |

**`alt` 를 따로 받지 않는다.**
**이유:** `name` 과 `alt` 를 따로 받으면 한쪽만 채운 호출이 생긴다. `alt=""` 인 순간 그림은
장식이 되고 누구의 얼굴인지가 아무 데도 남지 않는다. 하나로 받아 둘 다에 쓴다.

**이니셜을 직접 받지 않는다.**
**이유:** 따로 받으면 이름은 `김현우` 인데 이니셜은 `AB` 인 호출을 막을 방법이 없다.
보이는 글자와 읽히는 글자가 어긋난다.

**`className` 을 받지 않는다.**
**이유:** 바깥에서 정할 것이 크기뿐이고 그것은 `size` 가 이미 받는다. 구멍을 열면 네 번째
지름과 네 번째 배경색이 화면에 들어오고, 어느 것이 표준인지 판정할 근거가 사라진다.

### size 별 값 (`../../src/ui/avatar.tsx` 의 `cva` 정의)

| size      | 지름             | 이니셜 글자      | 간격 스케일 근거                                  |
| --------- | ---------------- | ---------------- | ------------------------------------------------- |
| `sm`      | 24px (`size-6`)  | 12px (`text-xs`) | 스텝 6 — [`../tokens.md`](../tokens.md) 12단계 안 |
| `default` | 40px (`size-10`) | 14px (`text-sm`) | 스텝 10 — 같은 표                                 |
| `lg`      | 64px (`size-16`) | 18px (`text-lg`) | 스텝 16 — 같은 표                                 |

**축이 하나인데 `cva` 를 썼다.** [`Alert.md`](Alert.md) 가 같은 경우다 — `alert.tsx` 의
`cva` 정의에도 축이 `variant` 하나뿐이다. 그 선례를 따랐다.
**바꿀 때 고칠 위치:** `avatar.tsx` 의 `avatarClass` 와 이 표, 두 곳이다.

### 형태

면은 **원**이다 — `rounded-full`. [`../tokens.md`](../tokens.md) 의 반경 3단계
(`rounded-lg` · `rounded-md` · `rounded-sm`) **밖이다.**
**이유:** 원은 반경 스케일의 한 단계가 아니라 모양 그 자체다. 같은 이유로 `badge.tsx` 의
상태 점도 `rounded-full` 을 쓴다. 이 컴포넌트가 처음 들이는 값이 아니다.

## states

| state         | 트리거             | 시각 변화                                                                                                                      |
| ------------- | ------------------ | ------------------------------------------------------------------------------------------------------------------------------ |
| default       | `src` 가 있다      | 원형 껍데기 안에 그림이 `object-cover` 로 꽉 찬다. 껍데기가 `overflow-hidden` 이라 밖으로 나가는 부분은 잘린다                 |
| hover         | 없다               | 상호작용 요소가 아니다. `avatar.tsx` 에 `hover:` 가 0건이다. 눌러야 하는 얼굴이면 그것을 `AppLink` 나 `Button` 으로 감싼다     |
| focus-visible | 없다               | 포커스를 받지 않는다. `tabindex` 를 주지 마라 — 이유: 읽기만 하는 그림이 포커스 순서에 끼면 키보드 이동 횟수만 늘어난다        |
| pressed       | 없다               | 누를 수 없다                                                                                                                   |
| disabled      | 없다               | 비활성 개념이 없다. 표시 전용이다                                                                                              |
| loading       | 없다               | 그림이 언제 도착하는지 모른다. 자리를 미리 잡아야 하면 그 자리에 [`Skeleton.md`](Skeleton.md) 를 놓고 도착한 뒤 바꿔 끼운다    |
| empty         | `src` 가 없다      | 이니셜이 선다. **`name` 이 빈 문자열이면 이니셜도 `aria-label` 도 비어 빈 원만 남는다** — 빈 이름으로 부르지 마라              |
| error         | 그림 주소가 깨졌다 | **감지하지 않는다.** 브라우저의 깨진 그림 표시가 그대로 남고 이니셜로 물러서지 않는다. 이유는 `avatar.tsx` 맨 위 JSDoc 에 있다 |

**전이를 넣지 마라.** `avatar.tsx` 에 `transition-*` 이 0건이다.
**이유:** 상태가 바뀌지 않는 표시 요소다. 전이할 대상이 없는데 붙이면
[`../tokens.md`](../tokens.md) 의 `motion-reduce:transition-none` 짝 규칙까지 딸려 온다.

## a11y

- a11y:label — 이름은 **한 번만** 읽힌다. `src` 가 있으면 `<img alt={name}>` 이, 없으면 껍데기의 `aria-label={name}` 이 갖는다. 두 경로가 겹치지 않는다 — 그림이 있을 때 껍데기에 `aria-label` 을 붙이면 스크린리더가 같은 이름을 두 번 읽는다. 이니셜 글자에는 `aria-hidden` 이 붙는다 — 이유: `김현` 을 소리로 들으면 이름이 잘린 것으로 들린다
- a11y:focus — 포커스 대상이 **0개**다. 이 컴포넌트는 포커스 순서에 끼지 않는다. 얼굴을 눌러 어딘가로 가야 하면 바깥의 링크가 포커스를 갖고 `Avatar` 는 그 안의 그림으로 남는다
- a11y:contrast — 이니셜 fg=`--muted-foreground` / bg=`--muted` 라이트 4.91 · 다크 6.51 ([`../tokens.md`](../tokens.md) `## 대비 검증` 의 대비값, 4.5:1 통과). **새 쌍을 만들지 않았다.** 그림 자체의 대비는 그림이 갖는 값이라 이 시스템이 정하지 않는다
- a11y:target — 클릭 대상이 **아니다.** 24x24 규칙(WCAG 2.5.8)이 걸리지 않는다. `sm` 이 24px 인 것은 우연이고, 누를 수 있게 만들려면 누르는 것은 바깥 요소이며 그 크기는 그 요소가 정한다
- a11y:role — `src` 가 있으면 `<img>` 의 `img` 역할, 없으면 껍데기에 `role="img"` 를 명시한다. **글자만 있는 껍데기에 `role="img"` 를 붙이는 이유:** 붙이지 않으면 이니셜 두 글자가 본문 글자로 읽혀 앞뒤 문장에 섞인다. `role="img"` 는 그 안쪽을 하나의 그림으로 묶고 이름은 `aria-label` 이 준다

## responsive

- **브레이크포인트 분기 0건.** `avatar.tsx` 에 `sm:` · `md:` 가 하나도 없다. 375px 에서나 1024px 에서나 지름이 같다
- 크기를 바꾸는 것은 화면 폭이 아니라 `size` 다. **`md:` 로 지름을 키우지 마라 — 이유:** 같은 자리에서 얼굴이 커지는 화면이 아직 0곳이다. 필요해지면 그때 `size` 에 반응형 축을 더할지, 부르는 쪽이 두 벌을 렌더할지 정한다
- `shrink-0` 이 걸려 있다. 좁은 가로 배치에서 옆 글자가 길어져도 원이 타원으로 눌리지 않는다

## 상호작용

- 없다. hover / focus-visible / active 대상이 아니다
