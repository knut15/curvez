# component: Breadcrumbs

purpose: 지금 있는 자리까지의 경로를 한 줄로 보이고 위 계층으로 돌아가는 길을 연다

## 근거 — daisyUI 와 shadcn/ui 의 마크업 구조만 옮겼다

### 1. 출처

| 항목      | 값                                                                                       |
| --------- | ---------------------------------------------------------------------------------------- |
| 참고한 곳 | daisyUI <https://daisyui.com/components/breadcrumbs/>                                    |
| 참고한 곳 | shadcn/ui <https://ui.shadcn.com/docs/components/breadcrumb>                             |
| 확인 날짜 | **2026-09-12**                                                                           |
| 옮긴 것   | 마크업 구조뿐이다. 클래스 이름은 한 글자도 옮기지 않았다 — 색·여백은 전부 이 시스템 토큰 |
| 소스      | [`../../src/ui/breadcrumbs.tsx`](../../src/ui/breadcrumbs.tsx)                           |

**daisyUI 문서에서 확인한 것**(2026-09-12): 감싸개가 `<nav>` 가 아니라 `<div class="breadcrumbs">`
이고 그 안이 `<ul>` 이다. 문서 예제에 aria 속성이 하나도 없고, 구분자를 의사 요소로 그리는지
실제 요소로 그리는지도 적혀 있지 않다.

**shadcn/ui 문서에서 확인한 것**(2026-09-12): `Breadcrumb` → `BreadcrumbList` → `BreadcrumbItem`
→ `BreadcrumbLink` 중첩이고, 마지막 자리만 `BreadcrumbPage` 로 바뀌며 `BreadcrumbSeparator` 가
항목 사이에 따로 선다. `BreadcrumbEllipsis` 로 가운데를 접는 조각이 하나 더 있다.
**그 문서 페이지에는 각 조각이 어떤 태그를 내는지도, 어떤 aria 속성을 붙이는지도 적혀 있지 않다.**
그래서 아래 `## a11y` 의 값은 문서에서 옮긴 것이 아니라 **이 스펙이 정한 것이다.**

### 2. 화면 사용처: 0곳

handwork 에도 scopulus-ui 문서 사이트에도 쓰인 적이 없다. **이 문서에는 `파일:줄` 이 없다.**
기존 9종의 `## 근거` 가 갖는 화면 근거가 여기에는 없고, 값의 출처는 위의 두 URL 과
[`../tokens.md`](../tokens.md) 둘뿐이다.

### 3. 두 출처와 다르게 한 것

| 무엇        | 출처                             | 여기                         | 이유                                                                             |
| ----------- | -------------------------------- | ---------------------------- | -------------------------------------------------------------------------------- |
| 바깥 태그   | daisyUI 는 `<div>`               | `<nav aria-label>`           | 경로는 이동 수단이다. 랜드마크가 없으면 목록으로 건너뛸 방법이 없다              |
| 목록 태그   | 둘 다 `<ul>` 계열                | `<ol>`                       | 순서가 뜻을 갖는다. 순서를 바꾸면 다른 경로가 된다                               |
| 구분자 자리 | shadcn 은 항목과 나란한 조각     | `<li>` **안**                | `<ol>` 의 자식으로 세우면 항목 3개가 "항목 5개" 로 읽힌다                        |
| 조각 수     | shadcn 은 7개                    | 컴포넌트 1개 + `items`       | 조각이 7개면 마지막 항목만 `BreadcrumbPage` 로 바꾸는 일을 부르는 쪽이 매번 한다 |
| 접기        | shadcn 에 `BreadcrumbEllipsis`   | **없다**                     | 접으면 펼침 상태가 생기고 이 컴포넌트가 상태를 갖는다. 긴 경로는 줄을 바꾼다     |
| 마지막 항목 | daisyUI 는 그냥 `<li>` 안의 글자 | `<span aria-current="page">` | 지금 자리를 색이 아니라 속성으로 말한다                                          |

## props

| 이름  | 타입                                 | 필수 | 기본값        | 의미                                                        |
| ----- | ------------------------------------ | ---- | ------------- | ----------------------------------------------------------- |
| items | `{ label: string; href?: string }[]` | O    | —             | 앞에서 뒤로 늘어놓은 경로. **마지막 항목이 지금 있는 자리** |
| label | `string`                             | X    | `"현재 위치"` | `<nav>` 의 이름                                             |

**`items[].href` 가 선택인 이유:** 색인 페이지가 없는 중간 계층이 있다. 그 항목은 링크 없이
글자만 나온다. **마지막 항목의 `href` 는 쓰이지 않는다** — 마지막은 언제나 링크가 아니다.

**`className` 을 받지 않는다.**
**이유:** 경로 줄은 페이지 제목 바로 위 한 자리에만 선다. 여백을 바깥에서 받으면 화면마다
다른 값이 생기고 어느 것이 표준인지 판정할 근거가 사라진다. 자리를 띄워야 하면 감싸는 쪽이 띄운다.

**구분자를 고르는 prop 을 두지 않는다.** 언제나 `/` 다.
**이유:** 구분자가 화면마다 다르면 같은 구조가 다른 것으로 읽힌다. 뜻을 갖지 않는 장식이라
고를 값이 아니다.

**`items` 가 1개여도 렌더한다.** 그 하나가 지금 자리이고 링크는 0개다.

## states

| state         | 트리거             | 시각 변화                                                                                                                        |
| ------------- | ------------------ | -------------------------------------------------------------------------------------------------------------------------------- |
| default       | —                  | 전체 `text-sm` fg=`--muted-foreground`. 마지막 항목만 `font-medium` fg=`--foreground`. 구분자 `/` 는 `--muted-foreground`        |
| hover         | 링크 위 포인터     | 링크 fg → `--ring`. `transition-colors duration-150 ease-out` + `motion-reduce:transition-none`. 면·이동·밑줄 변화 없음          |
| focus-visible | 키보드 이동        | `outline-2` + `outline-offset-2` + `outline-ring` + `rounded-sm`. 네 조각이 한 벌이다 ([`../tokens.md`](../tokens.md) `## 상태`) |
| pressed       | 없다               | 누름 상태를 만들지 않는다. [`../tokens.md`](../tokens.md) 가 "링크에 눌림 상태를 만들지 마라" 로 정했다                          |
| disabled      | 없다               | 비활성 개념이 없다. 갈 수 없는 계층은 `href` 를 주지 않으면 링크가 아닌 글자로 나온다                                            |
| loading       | 없다               | 스스로 데이터를 불러오지 않는다. 경로를 아직 모르면 부르는 쪽이 `Skeleton` 을 놓는다                                             |
| empty         | `items` 가 빈 배열 | `<nav>` 와 빈 `<ol>` 만 남는다. **빈 배열을 넘기지 마라** — 이유: 이름만 있는 랜드마크가 남아 낭독기가 빈 탐색 영역을 읽는다     |
| error         | 없다               | 상태를 갖지 않아 실패할 동작이 없다                                                                                              |

## a11y

- a11y:label — `<nav>` 에 `aria-label` 이 **언제나 붙는다**(기본값 `"현재 위치"`). **이유:** 한 화면에 `<nav>` 가 둘 이상이면 낭독기가 "탐색" 만 반복해 읽어 어느 것이 무엇인지 구별되지 않는다. 링크 글자는 그 자체가 이름이므로 `aria-label` 로 덮지 마라 — 보이는 글자와 읽히는 글자가 달라진다. **구분자 `/` 에는 `aria-hidden` 이 붙는다** — 장식이고, 읽히면 "슬래시" 가 항목마다 끼어든다
- a11y:focus — 포커스 대상은 `href` 가 있는 항목 수만큼이고 마지막 항목은 포함되지 않는다. 경로가 셋이면 2개다. **지금 자리를 링크로 만들지 마라** — 이유: 눌러도 같은 화면이라 아무 일도 일어나지 않는 탭 정거장이 하나 는다. 포커스 순서는 DOM 순서 = 왼쪽에서 오른쪽이다
- a11y:contrast — 링크·구분자 fg=`--muted-foreground` / bg=`--background` 라이트 **5.28** · 다크 **7.97**. 마지막 항목 fg=`--foreground` / bg=`--background` 라이트 **15.82** · 다크 **16.13**. hover fg=`--ring` / bg=`--background` 라이트 **6.02** · 다크 **12.96**. 셋 다 [`../tokens.md`](../tokens.md) `## 대비 검증` 에 이미 있는 쌍이고 4.5:1 을 넘는다. **새 대비 쌍이 생기지 않는다**
- a11y:target — 링크 한 줄의 높이는 `text-sm` 줄높이 **20px** 이다. 24x24 에 못 미친다. WCAG 2.2 의 Target Size (Minimum) 에는 줄 안에 있는 대상을 빼 주는 예외가 있지만 경로 줄이 그 예외에 드는지는 판정하지 않았다 — **확인 불가**다. 여백을 넣어 24px 로 키우면 경로 줄에 목록(`Menu`)과 같은 크기의 면이 생겨 두 컴포넌트가 구별되지 않는다. **바꿀 때 고칠 위치:** [`../../src/ui/breadcrumbs.tsx`](../../src/ui/breadcrumbs.tsx) 의 링크 `className` 한 줄과 이 항목이다
- a11y:role — `navigation`(landmark) 하나다. `<nav>` 가 이미 그 역할을 갖는다. **`role="navigation"` 을 손으로 붙이지 마라.** `<ol>` 에는 `role="list"` 를 붙인다 — **이유:** Tailwind preflight 가 `ol` 에 `list-style:none` 을 걸고, Safari 는 그 조건에서 목록 의미를 떼어 낸다. `<li>` 는 `listitem` 을 그대로 쓴다. 구분자는 `<li>` **안**의 `<span aria-hidden>` 이라 `listitem` 을 하나도 늘리지 않는다

## responsive

- 브레이크포인트 분기가 **0건**이다. 375px 에서 1920px 까지 같은 클래스가 적용된다
- 폭은 부모가 정한다. `max-w-*` 를 걸지 마라 — 이유: 페이지 폭은 [`PageShell.md`](PageShell.md) 가 정하고, 두 곳이 폭을 정하면 어느 값이 적용되는지 화면에서만 드러난다
- 좁아지면 **줄을 바꾼다.** `flex-wrap` 이고 가로 간격 `gap-x-1.5`(6px) · 세로 간격 `gap-y-1`(4px)이다. 옆으로 밀리는 스크롤을 만들지 않는다 — 이유: 가로 스크롤은 경로 뒤쪽(지금 자리)이 보이지 않는 채로 시작한다
- 375px 기준 쓸 수 있는 폭은 375 − 40([`PageShell.md`](PageShell.md) 의 `px-5` 두 번) = **335px** 이다. 항목 이름을 그 안에서 두 줄을 넘지 않는 길이로 쓴다

## 상호작용

- hover — `href` 가 있는 항목만. fg 가 `--ring` 으로 간다. 면·밑줄·이동 없음
- focus-visible — 같은 항목들. `outline-2 / outline-offset-2 / outline-ring / rounded-sm` 네 조각이 함께 붙는다
- 마지막 항목과 `href` 없는 항목은 hover / focus 대상이 아니다. 포인터에 반응하지 않고 탭 순서에도 없다
- 클릭은 주소를 바꾼다. `next/link` 가 낸 `<a>` 이므로 새 탭 열기와 주소 복사가 살아 있다
