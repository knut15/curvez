# component: Empty

purpose: 보여 줄 것이 0개일 때 그 자리가 비었다는 사실과 다음에 할 일을 말한다

## 근거 — shadcn/ui 의 마크업만 옮겼다

### 1. 출처

| 항목             | 값                                                      |
| ---------------- | ------------------------------------------------------- |
| 본 곳            | shadcn/ui <https://ui.shadcn.com/docs/components/empty> |
| 본 날짜          | **2026-09-12**                                          |
| 가져온 것        | 마크업 구조 — 가운데 정렬한 제목 · 설명 · 행동 하나     |
| 가져오지 않은 것 | 클래스, 그리고 조각을 여럿으로 쪼개는 방식(아래 2번)    |
| 아이콘           | 없다. 그림 자리를 만들지 않았다(아래 3번)               |

**이 값들은 화면에서 센 것이 아니다.** 기존 9종의 `## 근거` 에 있는 `파일:줄` 이 이 문서에는 없다.
**handwork 사용처: 0곳.** 어느 화면에도 쓰인 적이 없다.

### 2. 조각을 쪼개지 않는다

shadcn/ui 는 `Empty` · `EmptyHeader` · `EmptyMedia` · `EmptyTitle` · `EmptyDescription` ·
`EmptyContent` 여섯으로 쪼갠다. **여기서는 하나다.**
**이유:** 쪼개는 값은 "조각의 순서를 바꿀 수 있다" 인데, 빈 상태의 순서는 하나뿐이다 —
무엇이 없는지, 왜 없는지, 그래서 무엇을 할지. 순서를 고를 수 없다면 조각은 이름만 늘린다.
[`Alert.md`](Alert.md) 가 넷으로 쪼갠 것과 다른 판단인데, 거기는 아이콘이 있고 없고에 따라
격자가 바뀌어 조각마다 다른 규칙이 붙는다. 여기에는 그런 분기가 없다.

### 3. 행동을 자기가 만들지 않는다

행동은 `children` 이다. **버튼을 이 컴포넌트가 만들지 않는다.**
**이유:** 안에서 만들면 이 컴포넌트가 [`Button.md`](Button.md) 의 variant·size 를 다시 정하게 되고
그 값이 두 곳에 남아 한쪽만 고쳐진다. 그리고 빈 상태의 다음 걸음은 버튼일 수도 링크일 수도 있다 —
"글을 새로 쓴다" 는 `Button`, "목록으로 돌아간다" 는 `AppLink` 다. 둘을 이 컴포넌트가 고를 근거가 없다.

**그림(아이콘·일러스트) 자리도 만들지 않는다.**
**이유:** 라이브러리 소스에 `lucide-react` 를 넣지 않기로 했고, 자리만 열어 두면 부르는 쪽이 무엇을
넣을지 이 문서가 정할 수 없다. 필요해지면 `media` prop 을 따로 연다 —
**고칠 위치:** `../../src/ui/empty.tsx` 의 `EmptyProps` 와 이 절.

### 4. `Loading` · `Skeleton` · `Empty` 를 언제 나눠 쓰는가

| 무엇       | 쓰는 때                                                                 |
| ---------- | ----------------------------------------------------------------------- |
| `Skeleton` | **아직 기다린다.** 들어올 내용의 크기를 알아서 그 자리를 미리 잡아 둔다 |
| `Loading`  | **아직 기다린다.** 크기를 모르거나 한 곳에서 한 번만 알리면 되는 자리다 |
| `Empty`    | **기다림이 끝났다.** 그런데 결과가 0개다. 기다림이 아니라 결과를 말한다 |

**셋을 같은 자리에서 한꺼번에 보이지 마라.** 한 자리는 한 시점에 하나다 —
기다리는 동안 `Skeleton` 또는 `Loading`, 끝난 뒤 결과가 있으면 목록, 0개면 `Empty`,
실패면 [`Alert.md`](Alert.md) 의 `destructive` 다.

## props

| 이름        | 타입              | 필수  | 기본값 | 의미                                           |
| ----------- | ----------------- | ----- | ------ | ---------------------------------------------- |
| title       | `string`          | **O** | —      | 한 줄. 무엇이 없는지                           |
| description | `string`          | X     | —      | 왜 없는지 또는 어떻게 채우는지                 |
| children    | `React.ReactNode` | X     | —      | 행동 하나. `Button` 또는 `AppLink` 가 들어온다 |

**`cva` 를 쓰지 않는다.** 구분할 축이 0개다. variant 도 size 도 없다.

**`title` 을 `ReactNode` 로 열지 마라.**
**이유:** 글자 하나여야 줄 수와 폭을 이 문서가 정할 수 있다. 노드를 받으면 제목 자리에 목록이나
버튼이 들어오고, 그 순간 아래 `states` 와 `responsive` 의 값이 전부 추측이 된다.

**행동을 둘 이상 넣지 마라.** `children` 은 하나를 담는 자리다.
**이유:** 빈 상태의 다음 걸음이 둘이면 보는 사람이 무엇을 먼저 할지 고르게 된다. 그 선택이 필요한
화면이면 그것은 빈 상태가 아니라 시작 화면이다.

**`className` 을 열지 마라.**
**이유:** 테두리·여백·가운데 정렬이 한 벌이고, 그중 하나만 바꾸면 빈 상태가 화면마다 다르게 보인다.
어디에 놓일지는 부모가 정한다.

### 값 (`../../src/ui/empty.tsx`)

| 조각 | 값                                                                                          |
| ---- | ------------------------------------------------------------------------------------------- |
| 상자 | `flex w-full flex-col items-center` · `rounded-lg` · `border border-border` · `text-center` |
| 여백 | `px-5`(20px) · `py-10`(40px) · 조각 사이 `gap-2`(8px)                                       |
| 제목 | `<p className="font-medium">` — 500. 색은 상속(`--foreground`)                              |
| 설명 | `text-sm` · fg=`--muted-foreground` · `leading-relaxed` · `break-keep` · `max-w-[65ch]`     |
| 행동 | 설명에서 `mt-3`(12px) 더 떨어진다                                                           |

**전부 [`../tokens.md`](../tokens.md) 안의 값이다.** `px-5`·`py-10`·`gap-2`·`mt-3` 은 그 문서의
간격 12단계, `rounded-lg` 는 반경 3단계의 카드 값, `max-w-[65ch]` 는 그 문서가 설명 문단 폭으로
정한 값, `text-sm`·`font-medium`·`leading-relaxed` 는 타이포 스케일 안이다.

**배경색을 주지 마라.** 테두리만 있고 면은 부모의 것을 그대로 비춘다.
**이유:** [`../tokens.md`](../tokens.md) 의 `## 고도` 가 "면을 가르는 것은 그림자가 아니라 테두리
1px" 로 정했다. 빈 상태는 떠 있는 것이 아니라 비어 있는 것이라 면을 얹을 이유가 없다.

## states

| state         | 트리거          | 시각 변화                                                                                                                                                                                   |
| ------------- | --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| default       | —               | 테두리 1px 안에 제목·설명·행동이 세로로 가운데 정렬된다. 배경 없음                                                                                                                          |
| hover         | 없다            | 상자는 상호작용 요소가 아니다. `empty.tsx` 에 `hover:` 가 0건이다. **상자 전체를 누르게 만들지 마라 — 이유:** 누를 것은 안의 행동 하나뿐이고, 면까지 눌리면 어디를 눌러야 하는지가 흐려진다 |
| focus-visible | 없다            | 상자가 포커스를 받지 않는다. `tabindex` 를 주지 마라 — 이유: 읽기만 하는 영역이 포커스 순서에 끼면 키보드 이동 횟수만 늘어난다. 포커스 대상은 `children` 안의 행동 하나다                   |
| pressed       | 없다            | 누를 수 없다. 눌림 상태는 `children` 안의 `Button` 이 자기 규칙으로 갖는다                                                                                                                  |
| disabled      | 없다            | 비활성 개념이 없다. 표시 전용이다                                                                                                                                                           |
| loading       | 없다            | 스스로 데이터를 불러오지 않는다. 기다리는 동안은 이 자리에 [`Skeleton.md`](Skeleton.md) 또는 [`Loading.md`](Loading.md) 를 놓는다                                                           |
| empty         | **이것 자체다** | 다른 컴포넌트의 `empty` 행이 "없다" 인 이유가 이 컴포넌트다 — 보여 줄 것이 0개인 자리를 여기 하나로 모았다. **`title` 이 필수라 이 컴포넌트 자신이 비는 경우는 없다**                       |
| error         | 없다            | 실패를 말하지 않는다. **0개와 실패는 다르다** — 0개는 정상이고 실패는 아니다. 실패는 [`Alert.md`](Alert.md) 의 `destructive` 가 말한다                                                      |

**전이를 넣지 마라.** `empty.tsx` 에 `transition-*` 이 0건이다.
**이유:** 상태가 바뀌지 않는 표시 요소다. 전이할 대상이 없는데 붙이면
[`../tokens.md`](../tokens.md) 의 `motion-reduce:transition-none` 짝 규칙까지 딸려 온다.

## a11y

- a11y:label — 상자에 `aria-label` 을 붙이지 마라. **이유:** 안의 글자가 이미 이름이다. 라벨을 얹으면 보이는 글자와 읽히는 글자가 달라진다. `children` 안의 아이콘 버튼은 [`Button.md`](Button.md) 의 `a11y:label` 을 따라 `aria-label` 이 필수다
- a11y:focus — 포커스 대상은 **0개 또는 1개다.** `children` 이 없으면 0개, 있으면 그 안의 행동 하나다. 포커스 순서는 DOM 순서를 따르고 행동이 제목·설명 뒤에 있어 읽은 뒤 닿는다. **목록이 비어 이 컴포넌트로 바뀔 때 포커스를 여기로 옮기지 마라 — 이유:** 사용자가 다른 곳을 조작하는 중에 포커스가 튄다. 바뀐 사실을 알려야 하면 감싼 영역의 `aria-live="polite"` 가 할 일이고 이 컴포넌트의 일이 아니다
- a11y:contrast — 제목 fg=`--foreground` / bg=`--background` 라이트 **15.82** · 다크 **16.13**, 설명 fg=`--muted-foreground` / bg=`--background` 라이트 **5.28** · 다크 **7.97** ([`../tokens.md`](../tokens.md) `## 대비 검증` 에 이미 있는 쌍, 4.5:1 통과). 카드 안에 넣으면 배경이 `--card` 가 되어 라이트 16.73 / 5.59 · 다크 14.84 / 7.34 이고 그 쌍도 같은 목록에 있다. **테두리 `--border` 는 대비 목록에 넣지 않는다 — 이유:** 다크가 알파값이라 고정 쌍으로 계산되지 않는다고 같은 문서가 이미 정했다
- a11y:target — 상자는 클릭 대상이 아니라 24x24 규칙이 걸리지 않는다. `children` 안의 행동만 그 규칙을 받고 [`Button.md`](Button.md) 가 기본 크기를 40px(`h-10`)로 정했다
- a11y:role — 역할을 지정하지 마라. `<div>` 다. **`role="status"` 를 붙이지 마라 — 이유:** live region 이 되어 목록이 빌 때마다 낭독기가 제목과 설명을 통째로 읽는다. **제목을 `<h2>` 로 내지 마라 — 이유:** 이 컴포넌트가 페이지 본문에 놓일지 카드 안에 놓일지 모르므로 개요의 몇 번째 단계인지 정할 수 없다. 잘못 고른 단계 하나가 그 화면의 개요 전체를 어긋나게 한다. 단계를 붙여야 하는 자리면 제목을 밖에 두고 이 컴포넌트에는 설명만 남긴다

## responsive

- 브레이크포인트 분기가 **0건**이다. `empty.tsx` 전체에 `sm:`·`md:` 가 없다
- 좌우 `px-5`(20px) · 세로 `py-10`(40px)이 모든 폭에서 같다. **[`PageShell.md`](PageShell.md) 처럼 `md:` 에서 키우지 않는다 — 이유:** 그쪽은 화면 전체의 여백이라 폭이 넓어지면 함께 넓어져야 하지만, 이 상자는 폭이 넓어져도 담는 글이 늘지 않는다
- 폭이 `w-full` 이라 부모를 채운다. `max-w-*` 를 이 컴포넌트에 걸지 마라 — 이유: 폭을 두 곳에서 정하면 어느 값이 적용되는지 화면에서만 드러난다
- 설명은 `max-w-[65ch]` 에서 멈춘다. 1024px 페이지 폭에서도 한 줄이 65자를 넘지 않는다 — [`../tokens.md`](../tokens.md) 가 설명 문단 폭으로 정한 값이다
- `break-keep` 이 걸려 있어 한글이 낱말 가운데에서 끊기지 않는다. **375px 에서 제목이 두 줄이 되지 않게 쓴다** — 좌우 여백 20px 두 번을 빼면 제목에 쓸 수 있는 폭은 335px 이다

## 상호작용

- 상자 자신은 없다. hover / focus-visible / active 대상이 아니다
- 유일한 상호작용은 `children` 안의 행동 하나이고, 그것은 [`Button.md`](Button.md) 또는 [`AppLink.md`](AppLink.md) 의 규칙을 따른다
