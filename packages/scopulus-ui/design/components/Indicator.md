# component: Indicator

purpose: 다른 요소의 모서리에 표시 하나를 얹는다. 얹는 것은 주로 `Badge` 다

## 근거 — daisyUI 의 마크업만 옮겼다

### 1. 출처

| 항목             | 값                                                                      |
| ---------------- | ----------------------------------------------------------------------- |
| 본 곳            | daisyUI <https://daisyui.com/components/indicator/>                     |
| 본 날짜          | **2026-09-12**                                                          |
| 가져온 것        | 마크업 구조 — 감싸개가 `relative`, 표시가 `absolute`                    |
| 가져오지 않은 것 | 클래스, 변의 가운데 자리, 그리고 상자 밖으로 반쯤 나가는 배치(아래 2번) |
| 의존성           | 없다. `<span>` 둘이다                                                   |

**이 값들은 화면에서 센 것이 아니다.** 기존 9종의 `## 근거` 에 있는 `파일:줄` 이 이 문서에는 없다.
**handwork 사용처: 0곳.** 어느 화면에도 쓰인 적이 없다.

shadcn/ui 에는 같은 이름의 컴포넌트가 없다. 얹는 내용은 [`Badge.md`](Badge.md) 가 이미 갖고 있고,
이 컴포넌트는 그것을 어디에 앉힐지만 정한다.

### 2. 바깥 여백 — 주지 않는다. 표시가 상자 밖으로 나가지 않는다

daisyUI 의 `.indicator-item` 은 `transform: translate(50%, -50%)` 로 표시의 절반을 감싼 상자
**밖으로** 내보낸다. **그 방식을 쓰지 않는다.**

**이유 둘.**

1. **잘린다.** 밖으로 나간 절반은 조상 중 하나라도 `overflow-hidden` 이면 사라진다.
   이 라이브러리에서 `overflow-hidden` 을 가진 면이 이미 있다 — [`Progress.md`](Progress.md) 의 홈,
   그리고 이미지를 담는 [`AspectRatio.md`](AspectRatio.md) 안쪽이 그렇게 쓰인다.
2. **바깥 여백이 전염된다.** 잘리지 않게 하려면 이 컴포넌트가 자기 바깥에 여백을 만들어야 하는데,
   그러면 이것을 쓰는 모든 자리가 "여기에는 왜 여백이 붙어 있나" 를 다시 계산하게 된다.
   컴포넌트가 자기 바깥의 자리를 정하는 것은 [`PageShell.md`](PageShell.md) 이후로 이 시스템의 방식이
   아니다 — 자리는 감싼 쪽이 정한다.

**그래서 표시는 모서리 **안쪽**에 앉는다.** `top-0 right-0` 이고 `translate` 가 없다.
바깥 여백이 0이고, 부모가 무엇을 하든 잘리지 않는다.
**대가:** 표시가 감싼 것의 모서리를 덮는다. 아바타·이미지·아이콘 버튼처럼 모서리에 내용이 없는
대상에만 쓴다. 모서리까지 글자가 차는 대상에는 쓰지 마라.
**바꿀 때 고칠 위치:** `../../src/ui/indicator.tsx` 의 `POSITION` 과 이 절, 두 곳이다.

### 3. 화면 낭독기에 두 번 읽히지 않게 하는 순서

**DOM 순서가 `children` → 표시다.** 화면에서는 `absolute` 가 자리를 정하므로 순서가 보이지 않지만,
낭독기는 DOM 순서대로 읽는다.

| 순서              | 읽히는 말 | 판정                                    |
| ----------------- | --------- | --------------------------------------- |
| `children` → 표시 | "알림, 3" | **이것을 쓴다.** 무엇의 3인지 먼저 온다 |
| 표시 → `children` | "3, 알림" | 쓰지 않는다. 숫자가 먼저 나온다         |

**감싸개에 `aria-label` 을 붙이지 마라.**
**이유:** 붙이면 감싸개의 이름으로 한 번, 안의 글자로 한 번 **두 번 읽힌다.** 이름은 감싼 것과
표시가 각자 이미 갖고 있다.
**감싸개에 `role` 도 주지 마라.** 역할이 없는 `<span>` 이라 낭독기가 이 층을 통과해 안의 둘을
그대로 읽는다.

**표시 안에 누를 수 있는 것을 넣지 마라.** 표시에 `pointer-events-none` 이 붙어 있어 눌리지 않는다.
**이유:** 감싼 것이 버튼일 때 표시가 그 모서리를 덮는데, 표시가 포인터를 가로채면 버튼의 일부가
눌리지 않는 자리가 된다. 그 자리는 보는 사람에게 보이지 않는다.

## props

| 이름     | 타입                                                                 | 필수  | 기본값        | 의미                               |
| -------- | -------------------------------------------------------------------- | ----- | ------------- | ---------------------------------- |
| position | `"top-right"` \| `"top-left"` \| `"bottom-right"` \| `"bottom-left"` | X     | `"top-right"` | 네 모서리 중 하나                  |
| badge    | `React.ReactNode`                                                    | **O** | —             | 얹을 것. `Badge` 나 짧은 글자 하나 |
| children | `React.ReactNode`                                                    | **O** | —             | 표시가 붙을 대상. 상자 하나        |

**`cva` 를 쓰지 않는다.** 구분할 축이 `position` 하나뿐이라 평범한 객체 하나로 끝난다
(`../../src/ui/indicator.tsx` 의 `POSITION`).

**변의 가운데 자리(`top-center` · `middle-right` …)를 만들지 마라.** daisyUI 는 9칸을 전부 연다.
**이유:** 모서리 넷 밖의 다섯은 감싼 것의 내용 한가운데를 덮는다. 쓰이지 않을 다섯을 열어 두면
어느 자리가 의도된 것인지 판정할 근거가 사라진다.

**`offset`(밀어내기)을 받지 마라.**
**이유:** 위 `## 근거` 의 2번이 바깥 여백을 0으로 못박았다. 밀어내기를 열면 그 결정이 prop 하나로
뒤집히고, 잘리는 화면과 안 잘리는 화면이 섞인다.

**색·크기를 받지 마라.** 표시의 생김새는 `badge` 로 들어오는 것이 갖는다 —
[`Badge.md`](Badge.md) 가 그 값의 정본이다.

**`className` 을 열지 마라.**
**이유:** 이 컴포넌트가 정하는 값은 네 모서리 중 하나뿐이고 그것은 `position` 이 이미 정한다.

### 값 (`../../src/ui/indicator.tsx`)

| 조각           | 값                                                  |
| -------------- | --------------------------------------------------- |
| 감싸개         | `relative inline-flex` — 내용만큼만 차지한다        |
| 표시           | `absolute` + 모서리 두 방향 · `pointer-events-none` |
| `top-right`    | `top-0 right-0`                                     |
| `top-left`     | `top-0 left-0`                                      |
| `bottom-right` | `right-0 bottom-0`                                  |
| `bottom-left`  | `bottom-0 left-0`                                   |

**`z-index` 를 주지 않는다.** 표시가 DOM 상 나중이라 같은 층에서 뒤에 그려진다.
**이유:** 층을 만들면 이 감싸개가 새 stacking context 가 되고, 감싼 것이 팝오버·툴팁을 띄울 때
그 층 안에 갇힌다.

## states

| state         | 트리거 | 시각 변화                                                                                                                                                                                                    |
| ------------- | ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| default       | —      | 감싼 것이 그대로 보이고 지정한 모서리에 표시가 얹힌다. 감싸개 자신은 색도 테두리도 여백도 갖지 않는다                                                                                                        |
| hover         | 없다   | 감싸개는 상호작용 요소가 아니다. `indicator.tsx` 에 `hover:` 가 0건이다. hover 는 감싼 것이 자기 규칙으로 갖고, 표시는 `pointer-events-none` 이라 아예 받지 않는다                                           |
| focus-visible | 없다   | 감싸개가 포커스를 받지 않는다. `tabindex` 를 주지 마라 — 이유: 감싼 것이 이미 포커스를 받는데 감싸개까지 받으면 같은 자리에 탭이 두 번 걸린다                                                                |
| pressed       | 없다   | 감싸개는 누를 수 없다. 눌림은 감싼 것의 상태다                                                                                                                                                               |
| disabled      | 없다   | 비활성 개념이 없다. 감싼 버튼이 비활성이어도 표시는 그대로 보인다 — **표시를 함께 흐리지 마라. 이유:** 표시가 말하는 사실(읽지 않은 3건)은 버튼이 비활성이어도 여전히 참이다                                 |
| loading       | 없다   | 스스로 데이터를 불러오지 않는다                                                                                                                                                                              |
| empty         | 없다   | `badge` 가 필수라 표시가 빈 경우가 없다. **보일 것이 없으면 `Indicator` 를 쓰지 말고 `children` 을 그대로 렌더한다 — 이유:** 빈 표시가 얹히면 모서리에 까닭 없는 점이 남는다. 조건부 렌더는 부르는 쪽이 한다 |
| error         | 없다   | 상태를 갖지 않아 실패할 동작이 없다                                                                                                                                                                          |

**전이를 넣지 마라.** `indicator.tsx` 에 `transition-*` 이 0건이다.
**이유:** 자리가 바뀌지 않는다. `position` 은 렌더할 때 정해지고 그 뒤로 움직이지 않는다.

## a11y

- a11y:label — 감싸개에 이름을 주지 마라. **이유:** 이름을 주면 감싸개 이름으로 한 번, 안의 글자로 한 번 두 번 읽힌다. 표시의 뜻은 그 안의 글자가 말한다 — `badge` 에 숫자만 넣으면 "3" 만 읽히므로, 숫자만으로 뜻이 서지 않는 자리에서는 `badge` 안에 `sr-only` 글자를 함께 넣는다(예: `3`<span class="sr-only">건 읽지 않음</span>). **그 글자를 감싸개의 `aria-label` 로 올리지 마라 — 이유:** 그러면 안의 숫자와 라벨이 둘 다 읽힌다
- a11y:focus — 포커스 대상은 **감싼 것의 개수와 같다.** 감싸개도 표시도 포커스를 받지 않는다. 표시는 `pointer-events-none` 이고 포커스 가능한 요소가 아니다. 감싼 것이 버튼이면 그 버튼 하나가 전부다
- a11y:contrast — 감싸개는 자기 색을 갖지 않는다. 표시의 대비는 그 안에 들어온 것이 갖는다 — [`Badge.md`](Badge.md) 의 태그 칩은 fg=`--muted-foreground` / bg=`--muted` 로 라이트 **4.91** · 다크 **6.51** 이다([`../tokens.md`](../tokens.md) `## 대비 검증` 의 "칩 글자/칩 배경"). **표시가 감싼 것의 모서리를 덮으므로 배경이 있는 `badge` 를 쓴다 — 이유:** 배경 없는 글자를 이미지 위에 얹으면 실제 대비가 이미지에 따라 달라져 고정 쌍으로 계산되지 않는다
- a11y:target — 감싸개도 표시도 클릭 대상이 아니라 24x24 규칙이 걸리지 않는다. 감싼 것이 버튼이면 그 버튼이 규칙을 받고 [`Button.md`](Button.md) 가 `size="icon-sm"` 을 32x32 로 정했다. **표시가 그 32px 의 모서리를 덮어도 클릭 면적은 줄지 않는다** — `pointer-events-none` 이라 포인터가 그대로 통과한다
- a11y:role — 역할을 지정하지 마라. 감싸개도 표시도 역할 없는 `<span>` 이다. **`role="status"` 를 붙이지 마라 — 이유:** live region 이 되어 숫자가 1 오를 때마다 낭독기가 읽는다. 읽지 않은 알림 수가 바뀔 때마다 말을 끊는 것은 소음이다

## responsive

- 브레이크포인트 분기가 **0건**이다. `indicator.tsx` 전체에 `sm:`·`md:` 가 없다
- **폭을 갖지 않는다.** `inline-flex` 라 감싼 것의 크기가 곧 이 컴포넌트의 크기다. 감싼 것이 반응형이면 표시도 그 모서리를 따라간다
- 표시의 자리는 퍼센트가 아니라 모서리(`top-0 right-0`)라 감싼 것이 커지거나 작아져도 모서리에 그대로 붙어 있다
- 바깥으로 나가는 부분이 없으므로 **좁은 화면에서 표시가 화면 밖으로 밀리는 일이 없다.** 위 `## 근거` 의 2번이 그 대가로 모서리를 덮는 쪽을 골랐다
- 감싼 것이 `375px` 화면에서 줄바꿈되는 인라인 요소면 이 컴포넌트를 쓰지 마라 — 이유: `relative` 상자가 두 줄로 쪼개지면 `absolute` 표시가 어느 줄의 모서리에 붙을지 브라우저가 정한다

## 상호작용

- 없다. hover / focus-visible / active 대상이 아니다
- 감싼 것의 상호작용은 그대로 통과한다. 표시가 `pointer-events-none` 이라 포인터를 가로채지 않는다
