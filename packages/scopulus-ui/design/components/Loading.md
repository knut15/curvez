# component: Loading

purpose: 끝을 모르는 기다림 하나를 도는 고리로 알린다. 끝을 아는 진행은 `Progress` 가 맡는다

## 근거 — daisyUI 와 shadcn/ui 의 마크업만 옮겼다

### 1. 출처

| 항목             | 값                                                                                                            |
| ---------------- | ------------------------------------------------------------------------------------------------------------- |
| 본 곳            | daisyUI <https://daisyui.com/components/loading/> · shadcn/ui <https://ui.shadcn.com/docs/components/spinner> |
| 본 날짜          | **2026-09-12**                                                                                                |
| 가져온 것        | 마크업 구조 하나 — "도는 글리프 + 화면 낭독기용 글자"                                                         |
| 가져오지 않은 것 | 클래스. daisyUI 의 `loading-*` 도 shadcn 의 `Loader2Icon` 도 쓰지 않는다                                      |
| 아이콘           | 없다. `<svg>` 를 이 파일 안에서 직접 그린다 — `lucide-react` 를 라이브러리 소스에 넣지 않는다                 |

**이 값들은 화면에서 센 것이 아니다.** 기존 9종의 `## 근거` 에 있는 `파일:줄` 이 이 문서에는 없다.
**handwork 사용처: 0곳.** 어느 화면에도 쓰인 적이 없다.

### 2. daisyUI 에서 가져오지 않은 것

daisyUI 의 `loading` 은 여섯 모양(`spinner` · `dots` · `ring` · `ball` · `bars` · `infinity`)과
다섯 크기를 갖는다. **모양 축을 만들지 않는다.**
**이유:** 여섯이 전부 같은 사실("기다리는 중")을 말한다. 값이 같은데 이름이 여섯이면 어느 것이
의도인지 판정할 근거가 없다. [`../tokens.md`](../tokens.md) 가 같은 판단을 이미 내렸다 —
"값은 다른데 의미가 같다 → 나누지 않는다. 하나로 통일하고 이유를 남긴다".

### 3. `Loading` · `Skeleton` · `Empty` 를 언제 나눠 쓰는가

| 무엇       | 쓰는 때                                                                               |
| ---------- | ------------------------------------------------------------------------------------- |
| `Skeleton` | 기다리는 중이고 **들어올 내용의 크기를 안다.** 그 자리에 같은 크기의 면을 미리 놓는다 |
| `Loading`  | 기다리는 중인데 **크기를 모른다.** 또는 한 화면에서 한 번만 알리면 되는 자리다        |
| `Empty`    | **기다림이 끝났는데 결과가 0개다.** 기다림이 아니라 결과를 말한다                     |

[`Skeleton.md`](Skeleton.md) 의 `states` 는 "스피너를 따로 만들지 마라 — 같은 사실을 두 모양으로
말하면 어느 것이 의도인지 판정할 수 없다" 고 적었다. **그 문장은 목록·카드처럼 자리를 아는
경우에 적용된다.** 자리를 모르는 기다림(버튼을 누른 직후, 첫 로드 전 화면 전체)에는 흉내 낼
크기가 없어 `Skeleton` 을 놓을 수 없다. 그 자리를 이 컴포넌트가 맡는다.
**한 화면에서 둘을 같이 쓰지 마라 — 이유:** 한쪽은 자리를 잡고 한쪽은 도는데, 보는 사람은
둘이 다른 일을 기다린다고 읽는다.

## props

| 이름  | 타입                  | 필수 | 기본값          | 의미                                              |
| ----- | --------------------- | ---- | --------------- | ------------------------------------------------- |
| label | `string`              | X    | `"불러오는 중"` | 화면 낭독기가 읽는 이름. 동작 줄이기에서는 보인다 |
| size  | `"sm"` \| `"default"` | X    | `"default"`     | `sm`=16px(`size-4`) · `default`=24px(`size-6`)    |

**`cva` 를 쓰지 않는다.** 구분할 축이 `size` 하나뿐이라 평범한 객체 하나로 끝난다
(`../../src/ui/loading.tsx` 의 `SIZE`). 축이 둘이 되면 그때 `cva` 로 바꾼다.

**`value`(진행률)를 받지 마라.**
**이유:** 값이 있으면 그것은 `Progress` 다. 여기서 받으면 0% 로 멈춘 막대와 도는 고리 둘로 같은
사실을 말하게 된다.

**모양(`variant`)을 받지 마라.** 위 `## 근거` 의 2번에 이유가 있다.

**색을 받지 마라.** 고리는 `currentColor` 다. 감싼 곳의 글자색을 그대로 입는다 —
`text-muted-foreground` 가 기본이고, 버튼 안에 넣으면 그 버튼의 라벨색이 된다.

**`className` 을 열지 마라.**
**이유:** 이 컴포넌트가 정하는 값은 크기 하나이고 그것은 `size` 가 이미 정한다. 자리는 감싼 쪽이
정한다 — 가운데 세우려면 이것을 `flex justify-center` 안에 넣는다.

### 값 (`../../src/ui/loading.tsx`)

| 축        | 값                                                                          |
| --------- | --------------------------------------------------------------------------- |
| 글리프    | `viewBox="0 0 24 24"` · 반지름 9 · `stroke-width 2.5` · 4분의 1 호          |
| 바탕 고리 | 같은 원에 `opacity-25`. 장식이다                                            |
| 색        | `currentColor`. 감싸개가 `text-muted-foreground`                            |
| 움직임    | `animate-spin` (1초에 한 바퀴, 선형, 무한)                                  |
| 간격      | 고리와 글자 사이 `gap-2`(8px) — [`../tokens.md`](../tokens.md) 의 밀착 간격 |
| 글자      | `text-sm`(14px) · 평소 `sr-only`                                            |

## states

| state         | 트리거         | 시각 변화                                                                                                                                    |
| ------------- | -------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| default       | —              | 고리가 1초에 한 바퀴 돈다. 글자는 `sr-only` 라 보이지 않는다. **이 컴포넌트는 default 하나가 곧 전부다**                                     |
| hover         | 없다           | 상호작용 요소가 아니다. `loading.tsx` 에 `hover:` 가 0건이다. **만들지 마라 — 이유:** 기다리는 것을 누를 수 있게 보인다                      |
| focus-visible | 없다           | 포커스를 받지 않는다. `tabindex` 를 주지 마라 — 이유: 곧 사라질 요소가 포커스를 가지면 사라지는 순간 포커스가 `<body>` 로 떨어진다           |
| pressed       | 없다           | 누를 수 없다                                                                                                                                 |
| disabled      | 없다           | 비활성 개념이 없다. 표시 전용이다. 버튼을 비활성으로 만드는 것은 이것을 감싼 `Button` 이 한다                                                |
| loading       | **이것뿐이다** | default 가 곧 loading 이다. 이 컴포넌트가 화면에 있다는 사실 자체가 상태다                                                                   |
| empty         | 없다           | 스스로 내용을 갖지 않는다. `children` 을 받지 않는다                                                                                         |
| error         | 없다           | 실패는 말하지 않는다. **실패하면 이 자리를 `Alert variant="destructive"` 로 바꿔 낀다 — 이유:** 계속 도는 고리는 영원히 기다리라는 뜻이 된다 |

### 동작 줄이기 — `motion-reduce:` 짝

`animate-spin` 에 `motion-reduce:animate-none` 이 붙는다 (`../../src/ui/loading.tsx`).
[`../tokens.md`](../tokens.md) 의 `## 상태` 가 "전이를 넣으면 `motion-reduce:` 짝을 같은 줄에
넣는다" 로 정했고, [`Skeleton.md`](Skeleton.md) 가 그 규칙을 `animate-*` 로 넓혔다.

**동작 줄이기를 켠 사람에게 무엇을 보이는가 — 멈춘 고리 + 드러난 글자.**

| 켜기 전                           | 켠 뒤                                                   |
| --------------------------------- | ------------------------------------------------------- |
| 고리가 돈다                       | 고리가 4분의 1 호에서 멈춘다                            |
| 글자가 `sr-only` 라 보이지 않는다 | 글자가 고리 옆에 나타난다 (`motion-reduce:not-sr-only`) |

**글자를 함께 드러내는 이유:** 멈춘 4분의 1 호는 "25% 까지 찬 진행" 으로도 읽힌다. 움직임만 끄고
두면 이 컴포넌트가 `Progress` 로 보이고, 그것이 값 없는 기다림이라는 사실이 화면에서 사라진다.
움직임이 말하던 것을 글자가 대신 말하게 한다.
**고칠 위치:** `../../src/ui/loading.tsx` 의 `<span className="sr-only … motion-reduce:not-sr-only">`.

## a11y

- a11y:label — 감싸개가 `role="status"` 이고 이름은 **안의 글자에서 온다.** `aria-label` 을 붙이지 마라 — 이유: 라벨과 안의 글자가 둘 다 있으면 동작 줄이기를 켰을 때 보이는 글자와 읽히는 글자가 달라질 수 있다. 기본값은 `"불러오는 중"` 이고, 버튼 안에 넣을 때는 그 버튼이 하려는 일로 바꾼다 — `label="저장 중"`. `<svg>` 에는 `aria-hidden` 이 붙는다 — 그 뜻은 옆 글자가 이미 말한다
- a11y:focus — 포커스 대상이 **0개다.** 포커스 순서에 끼어들지 않는다. **버튼 안에 넣을 때 그 버튼을 `disabled` 로 만들면 포커스가 사라진다 — 그때는 `aria-disabled` 대신 `disabled` 를 주되, 포커스가 그 버튼에 있었다면 기다림이 끝날 때까지 다른 곳으로 옮기지 마라.** 이유: `disabled` 는 포커스를 잃게 하고, 잃은 포커스는 `<body>` 로 떨어져 키보드 사용자가 읽던 자리를 찾지 못한다
- a11y:contrast — 고리와 글자가 `currentColor` 다. 기본 감싸개 색 `--muted-foreground` / 바탕 `--background` 는 라이트 **5.28** · 다크 **7.97** 이다 ([`../tokens.md`](../tokens.md) 의 `## 대비 검증` 에 이미 있는 쌍 — "보조 설명·푸터/캔버스"). 고리는 그래픽이라 WCAG 1.4.11 의 **3:1** 이 하한이고 두 값 모두 넘는다. **바탕 고리(`opacity-25`)는 이 검사에서 뺀다 — 이유:** 알파 위 실제 색은 배경에 따라 달라져 고정 쌍으로 계산되지 않는다. 같은 문서가 다크 `--border` 에 대해 이미 같은 판단을 내렸다. 뜻은 앞의 호가 이미 말하므로 바탕 고리가 안 보여도 잃는 것이 없다
- a11y:target — 해당 없다. 클릭 대상이 아니라 24x24 규칙이 걸리지 않는다
- a11y:role — `status` 다 (`aria-live="polite"` 와 같다). **`role="progressbar"` 를 붙이지 마라 — 이유:** 그 역할은 값을 말하는 자리의 것이고 여기에는 값이 없다. **`role="alert"` 도 붙이지 마라 — 이유:** `assertive` 라 읽던 것을 끊는다. 기다림은 끊을 만큼 급하지 않다. **한 화면에 `Loading` 을 여럿 두지 마라 — 이유:** live region 이 여럿이면 같은 말이 여러 번 읽힌다. 영역마다 기다림을 보여야 하면 그 자리는 `Skeleton` 이다

## responsive

- 브레이크포인트 분기가 **0건**이다. `loading.tsx` 전체에 `sm:`·`md:` 가 없다
- 375px 에서도 1024px 에서도 같은 크기다. **`md:` 로 크기를 키우지 마라 — 이유:** 고리는 글자가 아니라 신호다. 폭이 넓다고 더 크게 알릴 이유가 없고, 분기를 늘리면 `size` 두 단계와 합쳐 네 가지 크기가 생긴다
- 폭을 갖지 않는다. `inline-flex` 라 내용만큼만 차지하고, 가운데 세우는 것은 감싼 쪽이 한다
- 동작 줄이기를 켜면 글자가 드러나 **가로 폭이 늘어난다.** 좁은 화면에서 버튼 안에 넣을 때는 그 버튼이 줄바꿈을 견디는지 본다 — 이유: `label` 기본값 "불러오는 중" 이 6글자라 `size="sm"`(16px) 과 합쳐 최소 100px 안팎을 차지한다

## 상호작용

- 없다. hover / focus-visible / active 대상이 아니다
- 유일한 변화는 `animate-spin` 이고, 동작 줄이기에서는 그것이 멈추고 글자가 대신 나온다
