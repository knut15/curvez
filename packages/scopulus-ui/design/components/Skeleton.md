## props

| 이름      | 타입                          | 필수  | 기본값 | 의미                            |
| --------- | ----------------------------- | ----- | ------ | ------------------------------- |
| className | `string`                      | **O** | —      | **크기를 정하는 유일한 수단**   |
| (그 밖)   | `React.ComponentProps<"div">` | X     | —      | `<div>` 의 속성을 그대로 받는다 |

**`className` 이 사실상 필수다.** 받은 소스에 `w-*` 도 `h-*` 도 없어서(`skeleton.tsx:7`),
주지 않으면 폭은 부모를 채우고 높이는 0 이 되어 화면에 아무것도 보이지 않는다.

**`width` · `height` prop 을 두지 마라.**
**이유:** Tailwind 클래스로 이미 정할 수 있고, prop 으로 열면 `className` 과 두 경로가 생겨
둘이 어긋날 때 어느 값이 적용되는지 화면에서만 드러난다.

**`variant="circle"` 을 만들지 마라.**
**이유:** `className="rounded-full"` 한 조각으로 끝난다. 한 번 쓰는 값에 이름을 붙이면 그 이름이
스펙에 남고, 실제로 쓰이는지는 아무도 세지 않는다.

**`count` prop(여러 개를 한 번에)을 두지 마라.**
**이유:** 줄마다 폭이 달라야 글을 흉내 낸다. 같은 폭 셋을 찍어 내면 표처럼 읽힌다.

### 받은 그대로의 값 (`skeleton.tsx:7`)

| 축     | 값                                                     |
| ------ | ------------------------------------------------------ |
| 면     | bg=`--muted`                                           |
| 반경   | `rounded-md` = 8px                                     |
| 움직임 | `animate-pulse` — 불투명도가 1 ↔ 0.5 로 2초마다 오간다 |
| 크기   | 없다. 부르는 쪽이 정한다                               |

**`rounded-md`(8px)는 [`../tokens.md`](../tokens.md) 의 반경 3단계 안이다.** 그 문서가
`rounded-md` 를 "아이콘 버튼 · 포커스 링 모서리" 로 적었지만, 3단계 안의 값을 쓰는 것 자체는
어긋나지 않는다. **글자 줄을 흉내 내는 자리에서는 `rounded-sm`(6px)으로 내린다. 이유:** 글자 한 줄의
높이가 14~16px 인데 8px 반경이면 양끝이 반원이 되어 알약처럼 읽힌다.

## states

| state         | 트리거         | 시각 변화                                                                                                                                                                                                           |
| ------------- | -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| default       | —              | bg=`--muted`, `rounded-md`, 불투명도가 1 ↔ 0.5 로 오간다. **이 컴포넌트는 default 하나가 곧 전부다** — 그 default 자체가 "불러오는 중" 이다                                                                         |
| hover         | 없다           | 상호작용 요소가 아니다. `skeleton.tsx` 에 `hover:` 가 0건이다. **hover 를 만들지 마라 — 이유:** 아직 없는 것을 누를 수 있는 것처럼 보인다                                                                           |
| focus-visible | 없다           | 포커스를 받지 않는다. **`tabindex` 를 주지 마라 — 이유:** 자리만 잡아 둔 상자가 포커스 순서에 끼면 키보드 사용자가 빈 곳을 여러 번 지나야 실제 내용에 닿는다                                                        |
| pressed       | 없다           | 누를 수 없다                                                                                                                                                                                                        |
| disabled      | 없다           | 비활성 개념이 없다. 표시 전용이다                                                                                                                                                                                   |
| loading       | **이것뿐이다** | 다른 컴포넌트의 `loading` 행이 "없다" 인 이유가 이 컴포넌트다 — 불러오는 중을 그리는 일을 여기 하나로 모았다. **스피너를 따로 만들지 마라. 이유:** 같은 사실을 두 모양으로 말하면 어느 것이 의도인지 판정할 수 없다 |
| empty         | 없다           | 스스로 내용을 갖지 않는다. `children` 을 넣지 마라 — 이유: 글자가 들어가면 그 글자가 `animate-pulse` 로 깜빡여 읽을 수 없다                                                                                         |
| error         | 없다           | 실패는 이 컴포넌트가 말하지 않는다. **불러오기가 실패하면 `Skeleton` 을 `Alert variant="destructive"` 로 바꿔 끼운다 — 이유:** 계속 깜빡이는 상자는 영원히 기다리라는 뜻이 된다                                     |

**`animate-pulse` 에 `motion-reduce:` 짝이 없다** (`skeleton.tsx:7`).
[`../tokens.md`](../tokens.md) 가 "전이를 넣으면 `motion-reduce:transition-none` 을 같은 줄에 넣는다"
를 화면에 나온 8:8 로 정했다. **`motion-reduce:animate-none` 을 같은 줄에 넣는다.**
**이유:** `animate-pulse` 는 화면에 여러 개가 동시에 깜빡이고 그 움직임이 끝나지 않는다. 전정기관
이상이 있는 사용자에게 화면 전체가 흔들리는 것으로 읽힌다. 움직임을 끈 자리에는 정지한
bg=`--muted` 면이 남고, 그것만으로도 자리를 잡아 두는 목적은 이룬다.
**고칠 위치:** `../../src/ui/skeleton.tsx:7`.

## a11y

- a11y:label — 이름을 붙이지 마라. **이유:** 자리만 잡아 둔 상자에 이름을 주면 스크린리더가 내용 없는 항목을 여러 번 읽는다. 불러오는 중이라는 사실은 **`Skeleton` 을 감싼 영역 한 곳에서 한 번만 말한다** — 그 영역에 `aria-busy="true"` 를 주고, 다 불러오면 `false` 로 바꾼다. 글자로도 알려야 하면 `sr-only` 로 "불러오는 중" 한 줄을 그 영역에 둔다. **`Skeleton` 하나하나에 그 글자를 붙이지 마라 — 이유:** 상자 다섯이면 같은 말이 다섯 번 읽힌다
- a11y:focus — 포커스 대상이 0개다. 포커스 순서에 끼어들지 않는다. **불러오기 전후로 포커스가 튀지 않게 하라** — 이유: `Skeleton` 이 실제 내용으로 바뀔 때 DOM 이 교체되므로, 그 안에 포커스가 있었다면 `<body>` 로 떨어진다. 그래서 포커스를 받지 않는 것이 이 컴포넌트의 값이다
- a11y:contrast — bg=`--muted` / 주변 bg=`--background` 의 대비는 라이트·다크 모두 **1.1 안팎으로 기준을 만족하지 않는다.** 그러나 이것은 **면과 면의 구분**이라 [`../tokens.md`](../tokens.md) 의 `## 대비 검증` 목록에 넣지 않는다 — 같은 문서가 카드/캔버스에 대해 이미 같은 판단을 내렸다("글자 대비 기준을 면 구분에 적용하면 통과할 수 없는 검사를 만든다"). **면이 안 보이는 것이 문제가 되는 자리면 `border border-border` 를 더한다 — 이유:** 그 문서가 정한 대로 이 사이트에서 면을 가르는 것은 색이 아니라 테두리 1px 이다
- a11y:target — 해당 없다. 클릭 대상이 아니라 24x24 규칙이 걸리지 않는다. **크기는 실제 내용과 같게 잡는다 — 이유:** 다르면 내용이 들어오는 순간 아래 요소가 밀려 읽던 자리를 잃는다. 글자 한 줄은 `h-4`(16px), 카드 제목은 `h-5`(20px), 버튼은 `h-10`(40px)이다
- a11y:role — 역할을 지정하지 마라. `<div>` 다. **`role="progressbar"` 를 붙이지 마라 — 이유:** 그 역할은 진행률을 값으로 말하는 자리의 것이고, 이 컴포넌트는 얼마나 남았는지 모른다. **`role="status"` 도 붙이지 마라 — 이유:** live region 이 되어 상자가 화면에 나타날 때마다 스크린리더가 빈 내용을 읽는다. 상태는 감싼 영역의 `aria-busy` 가 말한다

## responsive

- 브레이크포인트 분기가 **0건**이다. `skeleton.tsx` 전체에 `sm:`·`md:` 가 없다
- **크기가 없으므로 반응형도 부르는 쪽이 정한다.** 실제 내용이 `md:` 에서 크기가 바뀌면 `Skeleton` 도 같은 분기를 받아야 한다 — 이유: 두 크기가 다르면 768px 을 넘는 순간 화면이 한 번 더 밀린다
- 글자 줄을 흉내 낼 때 **마지막 줄을 짧게 한다** — `w-full` 둘에 `w-2/3` 하나가 한 벌이다. 이유: 모든 줄이 같은 폭이면 글이 아니라 표로 읽힌다
- 카드 목록을 흉내 낼 때 실제 목록과 같은 격자를 쓴다 — `grid gap-4 md:grid-cols-2`. [`../tokens.md`](../tokens.md) 의 화면에 나온 횟수(`md:grid-cols-2` 2회 · `gap-4` 5회)와 같은 값이다
- 개수를 화면 폭에 따라 바꾸지 마라. **이유:** 375px 에서 셋, 768px 에서 여섯을 그리면 폭이 바뀔 때 상자 수가 달라져 화면이 흔들린다. 한 번 정한 개수를 모든 폭에서 쓴다

## 상호작용

- 없다. hover / focus-visible / pressed 대상이 아니다
- 유일한 변화는 `animate-pulse` 이고, `motion-reduce` 에서는 그것도 멈춘다
