# component: Stat

purpose: 수치 하나와 그 이름을 한 쌍으로 보여 준다. 값이 갱신돼도 자릿수 때문에 자리가 흔들리지 않는다

## 근거 — daisyUI 에서 구조만 옮기고 요소를 바꿨다

### 1. 이 값은 화면에서 센 값이 아니다

**handwork 화면 사용처: 0곳.** 화면에 한 번도 나온 적이 없다.
기존 9종의 `## 근거` 에 있는 `파일:줄` 표가 이 문서에는 **없다.** 지어낼 수 없어서 비운 것이다.
값의 출처는 아래 벤더 한 곳과 [`../tokens.md`](../tokens.md) 뿐이다.

| 항목           | 값                                                       |
| -------------- | -------------------------------------------------------- |
| 참고한 곳      | daisyUI Stat — <https://daisyui.com/components/stat/>    |
| 옮긴 날짜      | **2026-09-12**                                           |
| 옮긴 것        | 이름이 위, 값이 아래라는 순서 하나                       |
| 옮기지 않은 것 | 요소와 클래스 전부. `stat` · `stat-title` 을 쓰지 않는다 |

**요소를 바꿨다. daisyUI 는 전부 `<div>` 다.** `stat-title` 도 `stat-value` 도 `<div>` 라
둘이 한 쌍이라는 사실이 클래스 이름에만 있다. 여기서는 `<dl>` · `<dt>` · `<dd>` 를 쓴다 —
이름과 값의 짝이 요소로 남는다.

**클래스는 우리 토큰으로 다시 썼다. 새 대비 쌍을 만들지 않았다.** 이름은
`--muted-foreground`, 값은 상속받은 `--foreground` 이고 둘 다
[`../tokens.md`](../tokens.md) 의 `## 대비 검증` 에 이미 있는 쌍이다.

### 2. daisyUI 와 다르게 정한 것

| 갈래      | daisyUI                                                                    | 우리                                |
| --------- | -------------------------------------------------------------------------- | ----------------------------------- |
| 요소      | `<div>` 만 쓴다                                                            | `<dl>` · `<dt>` · `<dd>`            |
| 조각      | `stat-title` · `stat-value` · `stat-desc` · `stat-figure` · `stat-actions` | **이름과 값 둘뿐**                  |
| 묶음      | `stats` 컨테이너가 테두리와 배치를 갖는다                                  | **없다.** 배치는 감싸는 쪽이 정한다 |
| 방향      | 가로 · 세로 변형                                                           | **없다**                            |
| 숫자 글꼴 | 자릿수 고정이 없다                                                         | `tabular-nums` 를 건다              |

**보조 설명(`stat-desc`)을 만들지 않았다. 이유:** 이 컴포넌트가 맡은 것은 "수치 하나와 그 이름"
둘이다. 셋째 줄을 열면 그 줄에 무엇이 들어갈지를 부르는 쪽마다 다르게 정하게 되고, 그러면
`Stat` 은 작은 카드가 된다. 면이 필요하면 그것은 다른 컴포넌트의 일이다.

**아이콘(`stat-figure`)과 버튼(`stat-actions`)을 만들지 않았다. 이유:** 같다. 표시 전용
한 쌍에 상호작용을 들이면 [`Button.md`](Button.md) 의 규칙을 이 문서가 다시 정해야 한다.

**묶음 컨테이너를 만들지 않았다. 이유:** 여러 개를 어떻게 늘어놓을지는 화면이 정하는 값이다.
컨테이너를 만들면 테두리와 간격을 여기서 정하게 되고, 그 값이 `Card` 와 어긋난다.

### 3. 왜 Data display 묶음에 들어가는가

이 묶음은 값을 보여 주기만 하고 받지 않는 것들이다. `Stat` 은 그중 **숫자 하나**를 맡는다.

## props

| 이름  | 타입     | 필수 | 기본값 | 의미                                |
| ----- | -------- | ---- | ------ | ----------------------------------- |
| label | `string` | O    | —      | 이 숫자가 무엇인지. `<dt>` 가 된다  |
| value | `string` | O    | —      | 다 만들어진 값 글자. `<dd>` 가 된다 |

**`value` 가 `number` 가 아니다.**
**이유:** 숫자를 받으면 여기서 포맷해야 한다. 천 단위 구분, 소수점 자리, 단위, 로캘이 전부
이 파일의 결정이 되고 부르는 쪽이 되돌릴 수 없다. `n.toLocaleString("ko-KR")` 의 결과를 받는다.

**셋째 줄(변화율·설명)을 받지 않는다.** 위 `### 2` 의 이유와 같다.

**`className` 을 받지 않는다.**
**이유:** 자리와 간격은 감싸는 쪽이 정한다. 구멍을 열면 `Stat` 마다 다른 여백이 생기고
나란히 놓았을 때 값의 아랫줄이 맞지 않는다.

### 값 (`../../src/ui/stat.tsx`)

| 조각      | 값                                                              | 스케일 근거                                           |
| --------- | --------------------------------------------------------------- | ----------------------------------------------------- |
| 이름      | `text-xs`(12px) · fg=`--muted-foreground`                       | [`../tokens.md`](../tokens.md) 크기 8단계의 메타 단계 |
| 값        | `text-2xl`(24px) · `font-semibold`(600) · `tracking-[-0.015em]` | 같은 문서의 h2 한 벌을 그대로 가져왔다                |
| 값의 색   | 없다 — 상속한다                                                 | `<body>` 의 `--foreground`                            |
| 자릿수    | `tabular-nums`                                                  | `font-variant-numeric: tabular-nums`                  |
| 이름 → 값 | `gap-1`(4px)                                                    | 간격 12단계 안(스텝 1)                                |

**값에 `text-4xl` 을 쓰지 마라.**
**이유:** 36px 은 [`../tokens.md`](../tokens.md) 에서 h1 의 단계이고 화면마다 h1 이 하나씩 있다.
같은 크기를 옆에 두면 봉우리가 둘이 되어 어느 것이 그 화면의 제목인지 판정할 수 없다.
24px 은 이름(12px)의 두 배라 한 쌍 안에서는 충분히 크다.

**`tabular-nums` 를 빼지 마라.**
**이유:** 기본 숫자는 글자마다 폭이 다르다. `1,284` 가 `1,285` 로 바뀔 때 숫자 전체의 폭이
달라져 옆에 놓인 다른 `Stat` 의 값과 아랫줄이 어긋난다.

## states

| state         | 트리거 | 시각 변화                                                                                                                                                                         |
| ------------- | ------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| default       | —      | 이름이 위(12px · `--muted-foreground`), 값이 아래(24px · 600 · 상속색). 면도 테두리도 여백도 없다                                                                                 |
| hover         | 없다   | 상호작용 요소가 아니다. `stat.tsx` 에 `hover:` 가 0건이다. 누를 수 있는 숫자면 그것을 `AppLink` 로 감싼다                                                                         |
| focus-visible | 없다   | 포커스를 받지 않는다. `tabindex` 를 주지 마라 — 이유: 읽기만 하는 쌍이 포커스 순서에 끼면 키보드 이동 횟수만 늘어난다                                                             |
| pressed       | 없다   | 누를 수 없다                                                                                                                                                                      |
| disabled      | 없다   | 비활성 개념이 없다. 표시 전용이다                                                                                                                                                 |
| loading       | 없다   | 스스로 데이터를 불러오지 않는다. 불러오는 중을 보여야 하면 값 자리에 [`Skeleton.md`](Skeleton.md) 를 놓는다                                                                       |
| empty         | 없다   | `value` 가 빈 문자열이면 이름만 남는다. **값이 아직 없을 때 `-` 나 `0` 을 지어 넣지 마라 — 이유:** `0` 은 "없다" 가 아니라 "0 이다" 라는 사실이다. 부르는 쪽이 렌더 여부를 정한다 |
| error         | 없다   | 상태를 갖지 않아 실패할 동작이 없다. 값을 못 구한 것은 부르는 쪽의 상태다                                                                                                         |

**전이를 넣지 마라.** `stat.tsx` 에 `transition-*` 이 0건이다.
**이유:** 값이 바뀌면 글자가 바뀔 뿐 색이나 크기가 바뀌지 않는다. 전이할 속성이 없다.

## a11y

- a11y:label — 이름과 값이 둘 다 보이는 글자다. `aria-label` 을 붙이지 마라 — **이유:** `<dt>` 가 이미 그 역할을 한다. 라벨을 얹으면 보이는 글자와 읽히는 글자가 달라진다. 값에 단위가 필요하면 `value` 글자 안에 넣는다 — 소리로도 함께 읽힌다
- a11y:focus — 포커스 대상이 **0개**다. 포커스 순서에 끼지 않는다
- a11y:contrast — 이름 fg=`--muted-foreground` / bg=`--background` 라이트 5.28 · 다크 7.97, 값 fg=`--foreground` / bg=`--background` 라이트 15.82 · 다크 16.13 ([`../tokens.md`](../tokens.md) `## 대비 검증` 의 대비값, 4.5:1 통과). `--card` 면 위에 놓아도 같은 문서의 카드 쌍(5.59 / 7.34, 16.73 / 14.84)이라 통과한다. **새 쌍을 만들지 않았다**
- a11y:target — 클릭 대상이 **아니다.** 24x24 규칙(WCAG 2.5.8)이 걸리지 않는다
- a11y:role — `<dl>` 이 목록, `<dt>`·`<dd>` 가 그 항목이다. **`role` 을 주지 마라 — 이유:** 요소가 이미 그 역할을 가진다. 여러 쌍을 한 `<dl>` 에 몰아넣지 않는 것도 같은 맥락이다 — 한 `<dt>` 에 `<dd>` 가 여럿 붙으면 "이 이름의 값이 여러 개" 라는 뜻이 된다

## responsive

- **브레이크포인트 분기 0건.** `stat.tsx` 에 `sm:` · `md:` 가 하나도 없다. 375px 에서나 1024px 에서나 글자 크기가 같다
- 폭을 정하지 않는다. `<dl>` 이 `flex flex-col` 이라 가로로는 부모가 주는 만큼 쓴다. 나란히 놓을 때 열 수와 간격은 감싸는 쪽이 정한다 — **`Stat` 에 `w-*` 나 `md:` 를 걸지 마라. 이유:** 폭을 두 곳에서 정하면 어느 값이 적용되는지 화면에서만 드러난다
- 이름이 길어 줄이 넘치면 두 줄이 된다. 줄 수를 제한하지 않는다 — 이유: 잘린 이름은 무엇의 값인지 판정할 수 없게 만든다

## 상호작용

- 없다. hover / focus-visible / active 대상이 아니다
