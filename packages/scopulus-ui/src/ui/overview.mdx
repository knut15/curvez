# handwork 디자인 시스템

**값은 전부 `packages/scopulus-ui/design/` 이 정본이다.** 이 스토리북은 그 값이 화면에서 실제로
어떻게 나오는지를 보여주는 곳이고, 값을 새로 정하는 곳이 아니다. 두 곳이 다르면 문서를 따른다.

## 무엇을 보고 있나

| 여기                             | 값의 정본                                          |
| -------------------------------- | -------------------------------------------------- |
| `shared/*` — 프리미티브 8종      | `packages/scopulus-ui/design/components/<이름>.md` |
| `entities/*` — 화면용 카드 2종   | 같은 디렉터리의 `CaseCard.md` · `LabCard.md`       |
| 색 · 간격 · 타이포 · 상태 · 고도 | `packages/scopulus-ui/design/tokens.md`            |

## 이 시스템이 만들어진 방식

**취향으로 정한 값이 없다.** 컴포넌트는 전부 기존 화면 코드에서 같은 클래스 문자열이 몇 번
반복되는지 세어 뽑았고, 그 횟수와 `파일:줄` 이 각 스펙의 `## 근거` 절에 있다.

| 컴포넌트    | 쓰던 것 |
| ----------- | ------- |
| PageShell   | 5회     |
| PageTitle   | 3+2회   |
| AppLink     | 6곳     |
| Separator   | 4회     |
| Badge       | 4+2회   |
| Card        | 2회     |
| Prose       | 2곳     |
| Button      | 1건     |
| ThemeToggle | 1건     |

화면에서 값을 못 뽑은 자리에는 값을 정하지 않았다. 고도(그림자)가 그렇다 — 앱 전체에서 `shadow` 가
**0건**이라 `tokens.md` 가 "쓰지 않는다" 로 못박았다.

## 테마를 바꾸는 법

**툴바의 테마 전환으로 바꾼다.** `ThemeToggle` 버튼을 눌러도 스토리북에서는 아무 일도
일어나지 않는다 — `next-themes` 프로바이더를 일부러 띄우지 않았기 때문이다.

프로바이더가 하나 더 생기면 테마가 앱과 다른 경로로 걸린다. 그러면 스토리에서 통과한 것이
실제 화면에서 깨져도 스토리는 계속 초록색이다. 토글하는 것은 `.dark` 클래스 하나뿐이니
데코레이터가 그 클래스만 직접 붙이는 편이 앱과 같은 경로다.

## 무엇이 자동으로 검사되나

```bash
pnpm --filter handwork test-storybook   # 스토리를 브라우저에서 그대로 돌린다
```

- **접근성** — 스토리마다 axe 가 돈다. 위반이 있으면 테스트가 실패한다.
  포커스 순서처럼 기계가 못 세는 것은 여전히 사람이 본다
- **상호작용** — `play` 가 붙은 스토리는 실제로 눌러 보고 결과를 확인한다.
  `Button/Disabled` 가 그 예다 — 불투명도만 낮추고 핸들러가 도는 구현은 화면에서 똑같이 보인다

```bash
node packages/scopulus-ui/scripts/check-contrast.mjs   # 대비 쌍 + 토큰 hex 동기
node packages/scopulus-ui/scripts/export-tokens.mjs    # Figma Variables JSON 내보내기
```

**시각 회귀는 없다.** 픽셀 단위 변화는 이 검사들로 잡히지 않는다.

## Figma

**코드에서 Figma 컴포넌트를 만들 수 없다.** REST API 는 노드 쓰기 자체가 없고, Variables
쓰기 엔드포인트는 Enterprise 조직 전용이다. 그래서 토큰을 W3C Design Tokens 형식으로
내보내는 데까지만 하고, 가져가는 것은 사람이 Tokens Studio 같은 플러그인으로 한다.

출력은 `packages/scopulus-ui/design/tokens.figma.json` 이고 라이트·다크 두 모드를 갖는다.
