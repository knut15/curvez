# 질문은 모아서 한 번에 한다

**사용자에게 할 질문은 라운드가 끝날 때 모아서 한 번에 묻고, 응답은 질문 원문과 짝지어 해당 워커에게 넘긴다.**

**이유:** 질문이 생길 때마다 물으면 사용자는 같은 맥락을 여러 번 다시 읽어야 하고, 앞 응답이 뒤 질문을
바꾸는 경우를 놓친다. 원문 없이 응답만 넘기면 워커는 무엇에 대한 응답인지 넘겨짚는다.

**패턴:**

- 워커는 질문을 `blocked_on` 에 `who: user` 로 남긴다. 직접 묻지 않는다
- 오케스트레이터가 모아서 번호를 붙여 한 번에 묻는다
- 실행해서 확인할 수 있는 사실은 질문으로 올리지 않는다

**판정 질문:** 한 라운드 안에서 사용자에게 두 번 이상 따로 물었는가?
