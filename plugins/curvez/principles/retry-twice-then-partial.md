# 두 번 재시도한 뒤 partial 로 보고한다

**같은 도구 호출이 실패하면 2회까지 재시도하고, 그래도 실패하면 `status: partial` 로 보고하며 무엇이 몇 번째에서 실패했는지 남긴다.**

**이유:** 같은 방법으로 세 번째에 성공하는 일은 드물다. 재시도를 계속하면 토큰과 시간만 쓰고,
실패 원인은 기록되지 않는다. 멈추고 보고해야 오케스트레이터가 다른 에이전트나 사용자에게 돌릴 수 있다.

**패턴:**

- 재시도마다 무엇을 바꿨는지 적는다. 바꾼 것이 없으면 재시도가 아니라 반복이다
- 보고에는 실패한 명령과 실제 출력을 그대로 넣는다. 요약하지 않는다
- 에이전트 정의의 `## 에러 핸들링` 표에 이 행을 둔다

**판정 질문:** 같은 실패를 세 번 이상 되풀이한 기록이 있는가?
