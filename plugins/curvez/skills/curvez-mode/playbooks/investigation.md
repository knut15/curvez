# 조사 (investigation)

**읽기 전용이다. 코드를 바꾸지 않고, 근거를 붙여 결론을 낸다.**

1. 질문을 한 문장으로 적는다
2. 코드, 문서, git 이력에서 근거를 찾는다. 라이브러리나 외부 API 에 관한 사실은 `research-brief` 절차로 1차 출처를 붙인다
3. 실행해서 확인할 수 있는 것은 실행한다. 명령과 출력을 남긴다
4. 확인하지 못한 것은 추측으로 메우지 않고 "확인 불가" 로 남긴다 (원칙: `principles/blocked-over-guessing.md`)
