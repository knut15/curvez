# 선택지 비교 조사

`SKILL.md` 절차 5단계에서 **후보를 고르는 조사**(라이브러리 선택, 접근 방식 선택)일 때 읽는다.
사실 확인형 조사(`이 API 가 되는가`)라면 읽을 필요가 없다.

---

## 후보를 먼저 확정한다

조사를 시작하기 전에 후보 목록을 적고 브리프에 남긴다. 최소 3개다.

| 후보 유형 | 반드시 포함하는 이유 |
|---|---|
| 널리 쓰이는 것 | 생태계·문서·타입 정의가 갖춰져 있어 기준선이 된다 |
| 프로젝트 스택이 이미 품고 있는 것 | 의존성을 늘리지 않는 선택지다. `package.json` 과 프레임워크 기본 기능에서 찾는다 |
| **아무것도 추가하지 않는 것** | 직접 구현하거나 그냥 안 하는 선택지. 이것이 이기는 경우가 실제로 있다 |

**후보를 조사 도중에 늘리지 마라.** 늘려야 할 근거를 찾았다면 그 사실을 `## 조사 경로` 에 적고
후보 목록을 다시 확정한 뒤 처음부터 같은 축으로 비교한다.
**이유:** 조사 중에 후보가 추가되면 먼저 조사한 후보만 깊게 파인 상태로 비교가 끝난다.
깊이의 차이가 우열로 보여, 늦게 들어온 후보가 근거 없이 탈락한다.

---

## 비교 축을 먼저 고정한다

후보를 보기 전에 축을 정한다. 축은 3~5개로 끊는다.

| 축 | 무엇을 확인하나 | 필요한 출처 |
|---|---|---|
| 프로젝트 버전 적합성 | 기준 버전에서 실제로 동작하는가. `peerDependencies` 와 충돌하지 않는가 | A: `package.json`, 릴리스 노트 |
| 플랫폼 커버리지 | `profile.json` 의 `stack` 이 요구하는 플랫폼을 전부 덮는가 (web / RN / 양쪽) | A: 공식 문서의 지원 플랫폼 표 |
| 제약과 탈출구 | 무엇을 못 하는가. 나중에 걷어낼 때 무엇을 다시 써야 하는가 | A: 공식 문서의 제약·한계 섹션, 이슈 트래커 |
| 유지 상태 | 최근 릴리스 날짜, 미해결 이슈 규모 | A: 릴리스 노트·태그 목록 |

**축을 후보에 맞춰 나중에 추가하지 마라.**
**이유:** 특정 후보가 강한 축을 뒤늦게 넣으면 그 후보를 뽑기 위한 근거를 만든 것이 된다.
결정자는 축이 언제 정해졌는지 알 수 없으므로 그 비교를 검증할 방법이 없다.

---

## 각 칸에 A 등급 출처를 붙인다

`## 선택지 비교` 표의 `근거 URL` 열은 후보당 최소 1개의 A 등급 URL 이다.
축 전체를 A 로 못 채운 후보는 **탈락시키지 말고** 채우지 못한 축을 `확인 불가` 로 적는다.

**이유:** 출처를 못 찾은 것과 나쁜 것은 다르다. 둘을 섞으면 문서가 부실한 후보가 성능이 나쁜 후보와
같은 취급을 받고, 결정자는 그 차이를 브리프에서 읽어낼 수 없다.

후보별 A 출처 인용은 `SKILL.md` 의 조사 상한(질문 1개당 5개)을 후보 단위로 적용한다 —
후보 3개면 최대 15개다. 웹 도구 호출 30회 상한은 브리프 단위 그대로다.
상한에 먼저 걸리면 조사가 끝난 후보까지만 표에 적고 나머지는 `확인 불가(조사 상한 도달)` 로 남긴 뒤
`status: partial` 로 보고한다.

---

## 순위를 매기지 마라

표를 채우는 것까지가 조사다. `권장`, `1순위`, `이걸 쓰면 된다` 를 쓰지 않는다.

**이유:** 최종 결정은 `architecture-setup` 에서 `curvez-architect` 가 한다. 조사자가 순위를 붙이면
결정자는 표를 읽지 않고 순위만 읽는다. 조사자가 몰랐던 제약(팀 숙련도, 기존 코드, 요구사항의 우선순위)이
반영될 자리가 사라진다.

대신 `결론 한 줄` 에는 **판정에 필요한 사실**을 쓴다.

| 쓰지 않는다 | 쓴다 |
|---|---|
| `B 를 권장한다` | `A 는 기준 버전에서 peer 충돌, B·C 는 충돌 없음. B 는 RN 미지원` |
| `C 가 가장 안전하다` | `세 후보 모두 웹은 덮음. RN 을 덮는 것은 C 뿐 (URL)` |

---

## 점검

- [ ] 후보가 3개 이상이고 그중 하나가 "아무것도 추가하지 않는 것" 이다
- [ ] 축이 3~5개이고 모든 후보에 같은 축을 적용했다
- [ ] 각 후보에 A 등급 URL 이 최소 1개 붙어 있다
- [ ] 못 채운 칸이 `확인 불가` 로 적혀 있다 (빈칸으로 두지 않았다)
- [ ] `결론 한 줄` 에 순위·권장이 아니라 사실이 적혀 있다
